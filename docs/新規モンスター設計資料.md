## 2. 新規状態異常の仕様

既存の気絶(stun)は「その場で行動権を1回没収、継続なし」という単発仕様。以下3つは全て新規追加。

### 拘束(bind)
- 継続ターン制(目安2〜3ターン)のデバフ。
- 効果中は通常攻撃が使えず、スキル(スキル1/スキル2/必殺技)しか選択できない。
- 使用可能なスキルが全てCT中の場合は、気絶と同じ「何もせずスキップ」になる。
- 気絶より長いターン数を付与できるのが強み(気絶は基本1ターンのみ)。

### 混乱(confuse)
- 単体/ランダム対象の攻撃行動は50%の確率で対象プールが敵→味方に反転する。
- 全体対象(tgt:'all')の攻撃行動は50%の確率で自陣(味方)に向く。
- バフ・回復系スキルは対象反転の対象外(誤爆させない)。

### 石化(petrify)
- 継続ターン制(目安2ターン)の行動不能デバフ。
- 石化中に攻撃を受けると、その攻撃は必ず会心になり、命中と同時に石化状態が解除される。
- 気絶/拘束と異なり「解除トリガーが攻撃を受けること」「解除と引き換えに大ダメージを許す」というハイリスクな状態。

## 3. タンクの多様化方針

既存・新規ともにタンクの大半が「挑発＋物理/魔法防御%アップ」に偏っていたため、型を分けた。

| 型 | 概要 |
|---|---|
| シールド型 | 挑発＋シールド(吸収)付与。%防御アップの代わり |
| ガーディアン型 | 挑発を使わず、味方1体を指定してその味方への攻撃を数ターン肩代わりする |
| カウンター型 | 能動的な挑発スキルを持たず、被弾時に確率で反撃/デバフを返す |
| 自己再生型 | 防御力より継続回復量で受けを上回る。挑発スキルなし |
| 自動シールド型 | パッシブで毎ターン自動的にシールドが蓄積。挑発スキルなし |
| 弱体設置型 | 自分を強化せず敵全体を弱体化して被害を減らす |

### 型を変更したキャラ

- **ブロック**(新規★4): シールド型に変更
- **ロックゴーレム**(既存m13): シールド型に変更(岩の鎧が剥がれて盾になるイメージ)
- **土蜘蛛**(新規★3): ガーディアン型に変更
- **アヌビス**(新規★4): カウンター型に変更(挑発スキルなし)
- **グリーンマン**(新規★5): 自己再生型に変更(挑発スキルなし)
- **タロース**(新規★5): 自動シールド型に変更(挑発スキルなし、スキル1は弱体設置型の攻撃技に差し替え)
