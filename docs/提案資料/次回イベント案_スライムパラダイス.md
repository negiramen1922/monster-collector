## 読み方

**表の読み方**: スキル・奥義の数値は「Lv1→Lv10」（上限10）。威力・回復量・効果量はLv10で1.5倍（Lv1→10を9等分）。ターン数は、味方への付与がLv5とLv10で+1ずつ、敵への付与がLv10で+1（上限5ターン）。通常攻撃・挑発・回数・CT・SP・確率はLvで変わらない。**パッシブの数値は「Lv1→Lv5」**（上限5、Lv5で1.5倍）。Lv1の値は10の倍数か偶数にそろえ、最大も整数になるようにしている。

**採点**: `tools/balance/power_lib.js` の採点式で Lv1 の値を測り、そのレアリティの予算に対する割合を書いた（スキル: CT2 18 / CT3 22 / CT4 27 に ★3 ×1.0・★4 ×1.1。奥義: 重さ1 35 / 重さ3 55 に ★3 ×1.0・★4 ×1.15）。スキルは85〜115%、奥義は100〜130%に収めた。
- 採点式は**防御の上昇（ポイント）と、最大HPの○%のシールド・回復を正しく数えない**（キャラ設計のルール 4章）。この2つが入るものは手で計算した（防御は「10ポイント・1ターンで1.5点」、最大HPの○%のシールドは「○点×1.2×対象の係数」、最大HPの○%回復は「○点×対象の係数」）。手で計算したものには「手」と書いた

**奥義の必要SP**: 「重さ×ロール」の表の値をそのまま書いた（`docs/提案資料/奥義SPの見直し.md`。タンク: 重さ1 40 / 重さ3 70、シューター: 重さ3 80）。

**自分のパッシブで復活・分裂したときは「倒れた」に数えない**（★2・★3の「味方が1体も倒れない」に触れない）。ほかの味方による蘇生は「倒れた」に数える。

**星刻特性の順番**: ★6 スキル1 → ★7 パッシブ → ★8 スキル2 → ★9 奥義 → ★10 そのキャラのコンセプトの大きな強化。Lvで伸びる数値（威力・効果量）は星刻で上げず、対象・回数・CT・ターン数・条件・付与率・追加効果で強くする。

用語は `docs/名称置き換え資料.md` の「状態の名前」にそろえた。**物理防御・魔法防御・SPDの上昇・低下はポイント**。
