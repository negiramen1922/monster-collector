## 同時ピックアップの★4（新キャラ案）

それぞれの★5と相性がよく、元ネタも近い★4を新しく作って、一緒にピックアップします。

### フェンリルの相棒: HPの多い敵を削るシューター

敵全体のHPを削っておき、フェンリルが仕留めて連続行動しやすくする役です。フェンリルの必殺技は「HPが50%以下の敵へ+50%」なので、そこまで削るのが仕事です。

| 候補 | 元ネタ | フェンリルとのつながり |
| --- | --- | --- |
| **ハティ**（おすすめ） | 北欧神話。月を追いかけ、最後に月を呑み込む狼 | フェンリルの息子。「遠くの大きな獲物（月）を追い詰める」のが、HPの多い敵を狙う性能と重なる |
| スコル | 北欧神話。太陽を追いかける狼 | ハティの兄弟で、同じくフェンリルの息子。炎属性にして次のイベントに取っておくのもあり |
| ウル | 北欧神話の弓と狩りの神 | シューターらしさは一番。ただしフェンリルとのつながりは薄い |

ハティの性能案（★4・風・シューター・ビースト）

- 通常攻撃: HPが一番多い敵に威力90%
- スキル1「月追いの遠吠え」(CT3): 敵全体に威力70%。HPの割合が高い敵ほど威力が上がる（最大+50%）
- スキル2「月喰らいの牙」(CT4): HPが一番多い敵に威力200%
- パッシブ「狩りの先触れ」: HPが70%以上の敵への与ダメージ+20%。フェンリルと一緒なら、さらに自分のSPD+10%
- 必殺技「月蝕」(SP100): 敵全体に威力170%。HPの割合が高い敵ほど威力が上がる（最大+60%）

### アバドンの相棒: 会心を伸ばすサポーター

味方の会心率を上げ、闇属性の味方には会心倍率も上げます。アバドンはパッシブで会心率+30%、スキル2が会心ダメージ+30%なので、一緒に使うと会心がほぼ確定になります。

| 候補 | 元ネタ | アバドンとのつながり |
| --- | --- | --- |
| **黙示の蝗（もくしのいなご）**（おすすめ） | 『ヨハネの黙示録』9章。底なしの淵から湧き出る、王冠と人の顔、蠠の尾を持つイナゴ | アバドンはこのイナゴの王。「王に従う群れが王を強くする」は元ネタそのまま |
| ベルゼブブ | 蝇の王と呼ばれる大悪魔 | 同じ聖書系の悪魔。群れを従える点も近い。ただし★4にするには大物すぎる |
| アポリオン | アバドンのギリシャ語での名前 | 同一人物なので、別キャラにすると紛らわしい |

黙示の蝗の性能案（★4・闇・サポーター・デーモン）

- 通常攻撃: 威力70%（魔法）
- スキル1「群れの羽音」(CT3): 味方全体の会心率+15%（2ターン）。闇属性の味方は会心倍率も+20%
- スキル2「蠠の尾」(CT4): 敵単体に威力140%。物理防御-20%（2ターン）
- パッシブ「王への献身」: 味方が会心を出すたびに、自分のSP+5（1ラウンドに20まで）
- 必殺技「黙示の群れ」(SP100): 3ターン、味方全体の会心率+25%。闇属性の味方は会心倍率も+40%

作るにあたって

- 新しい仕組みが2つ要ります。「HPが一番多い敵を狙う」対象と、「会心倍率アップ」のバフです。どちらも小さな追加ですむので、他のキャラにも使えます。
- 数字はパワー予算（★4は×1.1）に合わせて決め、シミュレーションで「相棒と組むとどれだけ強くなるか」を測ってから決めます。
- 立ち絵（ドット絵）が必要です。用意できないうちは「画像準備中」の付きの表示になります。
- ガチャでは、各イベントのピックアップに★4を並べます。イベントのクエストにも護衛として登場させられます。

決めてほしいこと: キャラ（ハティ・黙示の蝗でよいか）、立ち絵をどうするか、性能案の方向。

10層をクリアすると挑めるおまけの層です。各イベントに1つずつ作り、「ステージ効果」で編成を考えさせます。ステージに入る前の画面で効果を見せ、戦闘中も画面の上に出します。プレイヤーのLvは300が上限なので、推奨Lv300・ボス★8くらいから測って合わせます。

- **フェンリルは「1. 神々の黄昏」**。主役の伝承に沿っていて、種族で得する・損する形が分かりやすいです。
- **アバドンは「4. 底なしの淵」**。「弱った敵を仕留める」というアバドンの持ち味がそのままルールになります。
- どの案も、ステージに効果を付ける仕組みを新しく作ります。1〜6は同じ仕組みで作れ、7・8は編成画面と勝利条件に手が入ります。
- 報酬の案: 初回クリアで結晶と、主役のソウル（★上げに使える）。

## アバドン調整案

同じ仲間4体（タイタン・ホーリードラゴン・シースライム・ケルベロス）に★5アタッカーを1体ずつ入れて、ハードの高難度ステージ6つ（q5〜q7）で戦わせました。★は8、スキルと必殺技はLv12です。勝率は強い仲間に引っ張られて差が出にくいので、1戦あたりの与ダメージで比べます。

| キャラ | 1戦あたりの与ダメージ |
| --- | --- |
| 死神 | 約35,000 |
| フェンリル | 約31,000 |
| 雷電 | 約30,000 |
| バハムート | 約28,000 |
| **アバドン（今）** | **約18,600** |

アバドンはほかの★5アタッカーの6割ほどしかダメージを出せていません。理由は2つです。

- 必殺技「無底坑」が**SP120（一番重い）なのに単体攻撃**です。ほかの4体はどれも全体攻撃です。
- スキルも単体ばかりで、敵が多いウェーブでは「倒すとスキルのCT-1」があまり回りません。

試した案（数字は同じ測り方の与ダメージ）

| 案 | 変更 | 与ダメージ |
| --- | --- | --- |
| **案A: 必殺技を全体に** | 無底坑を「敵全体に威力220%。HPが30%以下の相手には威力+100%」に。必要SP 120→110 | 約22,000 |
| **案B: 倒すほど勢いづく** | スキル2「奈落の乱撃」を「ランダムな敵に威力60%×7」に（今は単体55%×7）。パッシブに「敵を倒したときSP+20」を足す | 約22,800 |
| **案C: AとBの両方** | 上の2つを合わせる | **約31,100** |

- 必殺技の威力を上げるだけの案（380%→450%、SP100）や、必殺技をランダムな多段にする案も試しましたが、どれも約18,000〜22,000止まりでした。
- **おすすめは案C**です。フェンリルとほぼ同じ強さになります。「底なしの淵にまとめて引きずり込む」「蝗の群れのように手当たり次第に襲う」と、元ネタにも合います。
- 案Cを入れると、イベントのボスのアバドンも強くなります。決まったら各層の勝率を測り直して、フェンリル側とそろえます。
- すでにアバドンを持っている人には強化です。弱くなる点はありません。
