# バベル 種族の塔案（陽の塔・陰の塔の作り直し）

**実装ずみ**: 塔は「均衡の塔(全員)・秩序の塔・混沌の塔」。試験場 `index.html?lab=babel` で遊べます。

2026-10-07 · 天の塔10階はそのまま。属性わけの2塔を種族わけに作り直す案。

## なぜ作り直すか

属性でわけると、エルフ9体が全員 草か地なので **陽の塔ではエルフが1体も使えません**。
種族シナジー（5体で最大）を塔の中で組めない種族が、陽で5つ・陰で2つありました。
手持ち検査のコンテンツとしてこれは歪なので、わけかたを種族に変えます。

属性にはモンスターごとの個性（相性）がありますが、種族にはそれがないぶん、
**塔＝種族の広さの検査 / 階＝属性と編成の組み方の検査** と、検査する軸を2つに分けられます。
属性わけだと両方が同じ軸でした。

## 確かめかた

天の塔と同じく、各階で実測します。

- **勝てる想定**: その育ちで **勝率80%以上**
- **勝てない想定**: **1段上の育ち**でも **勝率20%以下**

道具は `tools/babel_sim.js`（勝率を出す）と `tools/babel_tune.js`（階ごとの敵の底上げを二分探索で出す）。
敵の強さ（`BABEL_STRENGTH`）と育ちの段階（`BABEL_GROW`）は天の塔と共通のまま変えません。

## 実装で要るもの

1. `BABEL_TOWERS` の `allow` を属性から種族に変える（`allow` の中身と `babelAllowed` の判定）
2. `BABEL_FLOORS.yo` / `.in` を上の表で差し替え（キー名も `sei` / `ma` に変える）
3. 塔の名前（下の「決めること」）
4. 各階の底上げを `babel_tune.js` で出し直す

## 決めること

- 決定ずみ: **均衡の塔（全員）/ 秩序の塔 / 混沌の塔**。天の塔は均衡の塔に改名した。

## 実測で直したこと（1巡目のあと）

実際に回したら、6階が「勝てる想定より勝てない想定のほうが強い」状態だった。
原因はどれも同じで、**勝てない想定は育ちが1段上なので、条件に合う側へ+100%くらいでは逆転しない**こと。
天の塔の効く階は、必ず「条件を外した側への罰」も書いてあった。そこに合わせた。

## 作り直し（2パーティ戦の廃止・5階と10階に条件を集める）

全階にステージ効果があるせいで、どの階も同じ味になっていた。リズムを変えた。

| 階 | 形 |
| --- | --- |
| 1〜4・6〜9 | **ふつうの戦い**。敵の種族と属性を階ごとに寄せる。有利な属性で組めば勝てる |
| **5** | **ステージ効果**（均衡=やけど / 秩序=ロール / 混沌=毒） |
| **10** | **特殊ステージ**。ボス1体の最大HP+120%＋取り巻き |

2パーティ戦は廃止した。ステージIDの `_0`/`_1`、`STATE.babelUsed`、前半後半の重複チェックが消えた。

### 通常階の合否は「属性の有利/不利」で決める

1巡目は「硬い」「速い」などの質で分けたが、**22/30階が基準を外れた**。
勝てない想定は育ちが1段上なので、質の違いでは跳ね返せない。
属性なら 1.5倍と0.7倍で **2.14倍**の差が付くので跳ね返せる。種族寄せは味付けとして残した。

### 10巡かかって分かったこと

ここが今回いちばんの収穫。どれも「有利属性で組ませたつもりが、実際には有利になっていなかった」。

| 落とし穴 | 中身 |
| --- | --- |
| **火力役がいない属性がある** | 秩序の水は6体いても火力役(アタッカー+シューター)が1体、混沌の光は5体で1体。揃えても殴れない |
| **5体目が相性の外** | 不利な属性が4体しかないと5体目が別属性になる。無属性は**どの属性とも1.0倍**なので罰をまったく受けない |
| **勝てない想定にタンクがいると落ちない** | 1.5倍のダメージを受けてもタンクが耐え、相性の罰が効かなくなる |
| **同属性は1.0倍** | 敵が火の階に火の編成を当てても相性の利はゼロ |
| **WAVEの属性が混ざる** | 有利なのが最後のWAVEだけ、という階が複数あった |
| **★5が相性をひっくり返す** | 勝てない想定に雷電★5がいると0.7倍でも押し切る。勝てる側にも★5を入れて釣り合わせる |
| **★1は1.5倍が乗っても火力にならない** | Lv200固定でも素のステータスが低い |
