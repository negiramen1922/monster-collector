紅蓮の九尾の抱き合わせピックアップ。ID は **m170 / sprite「170」**（m169 が最新、170 が次）。

## 共通の仕様

```
256x256ピクセル、透明背景のPNG。ドット絵（ピクセルアート）。
全身が入る立ち姿で、上下左右に5ピクセル前後の余白。
正面よりやや斜めを向く。輪郭ははっきりさせる。
暗い紫の背景（#1b1730）に置くので、黒に近い色で塗りつぶさない。
既存のモバイルRPGの仲間キャラと並ぶので、同じ画面に置いて浮かない密度。
```

## 牛鬼（うしおに）

九尾の狐（玉藻前）と並ぶ大妖怪。後衛の味方をかばい、受けるダメージを代わりに背負うタンク。
**「他人のぶんを背負う巨体」**がこのキャラの一行説明です。

```
ドット絵、256x256、透明背景、全身の立ち姿。
牛の頭を持つ鬼。二本の脚で立つ巨漢。人の2倍近い体格で、肩幅が異様に広い。
牛の頭。太く前に張り出した二本の角。鼻に鉄の輪。口から蒸気のような白い息。
目は燃える橙で、瞳は横長の牛の瞳孔。獣だが知性がある目つき。
肌は焼けた鉄のような赤銅色。肩・背・腕の外側に、溶岩が固まったような黒い甲。
甲の割れ目から橙の熱が透ける。火は纏わせず、体の内側が熱い表現にとどめる。
腰に注連縄（しめなわ）。そこに札が何枚か垂れている。和風の意匠はここで出す。
下半身は獣の脚で、蹄。足元に焦げた地面と薄い陽炎。
左腕を前に大きく広げ、後ろの誰かを隠すように構える。右手は握った拳を下げる。
武器は持たせない。素手と体で受ける役。
```

### 外してほしいもの

```
牛車・荷車は出さない（運ぶ妖怪ではなく、守る役）。
海・波・水の要素は出さない（炎属性なので、海辺の妖怪という出自は絵に出さない）。
蜘蛛の脚にはしない（牛鬼の別伝だが、同じイベントに土蜘蛛がいるので混ざる）。
全身を炎で包まない（マグマゴーレム m72・マグマスライム m33 と見分けがつかなくなる）。
鎧は着せない（タイタン m54 が黄金の鎧なので、こちらは生身と甲）。
かわいい牛にはしない。角は必ず二本、太く。
```

## 並べたときの見分け（既存の炎キャラとの描き分け）

| | 既存 | 牛鬼はこう違える |
|---|---|---|
| マグマゴーレム（m72・炎タンク） | 溶岩の体そのもの | 牛鬼は**生身の赤銅色**。熱は甲の割れ目からだけ |
| マグマスライム（m33・炎タンク） | 不定形 | 牛鬼は**明確な巨漢の人型** |
| 鬼火（m127・炎サポート） | 赤い炎の塊 | 牛鬼は**炎を纏わない** |
| タイタン（m54・土タンク） | 黄金の鎧の巨人 | 牛鬼は**鎧なし・和風の注連縄** |
| 九尾の狐（m116・炎シューター） | 妖艶・九本の尾 | 牛鬼は**武骨・角と筋肉**。隣に並べて対になる |

**九尾と2体で並ぶ絵が最終ウェーブに出ます。** 九尾が細く妖艶なら、牛鬼は太く武骨。
色は九尾が朱と白なら、牛鬼は赤銅と黒。同じ炎属性でも**体型と質感で正反対**になるのが狙いです。
