## 結論：本当の通貨はスタミナ1つ

育成素材はすべて**育成クエストかステージ周回**から出ます。育成クエストは4種類ありますが**スタミナは1つのプールを共有**しているので、EXPを掘るあいだはゴールドも霊素鉱もルーンも増えません。

つまりどの素材も「スタミナを何に替えるか」という配分の問題で、**素材ごとの不足は見かけで、本当の制約はスタミナです**。

### 1スタミナで手に入るもの（各クエストの最上段）

|---|---|---|
| EXPの泉 5段 | 20⚡ | **68 EXP** |
| 黄金の洞窟 5段 | 20⚡ | 2,500G → **新案 1,750G** |
| 霊素の鉱脈 5段 | 20⚡ | **霊素鉱30個** + 霊素核I 0.2個 + 霊素核II 0.1個 |

| 神話級ステージ | 10⚡ | ワザ素材 **2.79個**(TierI換算) + ソウル約0.26個 + 石3〜10 |

## 5体を完成させるのに必要なスタミナ

★10・Lv300・ワザ4つLv11・遺物5個Lv60・ルーンTierX×20個まで。

| 何に | スタミナ | 自然回復だけなら |
|---|---|---|
| **ソウル**（★10×5体 = 7,500個） | **28,847⚡** | **100日** |
| **EXP**（Lv300×5体） | 15,524⚡ | 54日 |
| **ワザ素材**（4ワザLv11×5体） | 10,892⚡ | 38日 |
| **ゴールド**（壁+星刻、新案1,750G/⚡） | 10,163⚡ | 35日 |
| ルーン（TierX×20個） | 3,600⚡ | 13日 |
| 霊素鉱（遺物5個Lv60） | 2,534⚡ | 9日 |
| **合計** | **71,560⚡** | **248日** |

石でスタミナを買い切ると**20日・102,000石**。つまり**石を注いでも最速20日**で、自然回復だけなら8ヶ月です。

**一番重いのはソウル（全体の40%）**で、ここが★のペースを決めています。石では飛ばせません。
