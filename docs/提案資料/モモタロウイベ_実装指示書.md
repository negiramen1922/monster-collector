# モモタロウイベ 実装指示書

Oct 5, 2026 · @ねぎらーめん

`docs/提案資料/次回イベント案_モモタロウ.md` の決定内容を、index.html に入れて**試験場で遊べる**ようにするための指示書。中身（数値・文言）の正は企画の資料のほう。食い違ったら企画の資料に合わせ、この指示書を直すこと。

開催予定: 10/13ごろ〜10/26ごろ（「豊穣の女神」と2本同時）。

**前提（2026-10-06 更新）**: この作業は、`第1段_実装指示書.md`（奥義SP・スキルLv/パッシブLv）と `公開日まで隠す仕組み_実装指示書.md` が入ったあとに行う。

- 奥義の必要SPは「重さ×ロール」の表の値をそのまま書く（戦闘中のロール補正はなくなっている）
- スキル・奥義の数値は Lv1 の値。Lv10で1.5倍、パッシブは Lv5で1.5倍（第1段で入る `lvScale`）
- 新キャラ6体と新遺物2つには `releaseAt`（イベントの `startAt` と同じ）を書く。日付の前はガチャ・図鑑などに出ない

## 1. 進め方

1. まず**試験場**（`index.html?lab=momotaro`）で遊べるところまで作る。本番のイベント一覧には、日付が来るまで出さない（`?lab=` で開くと、`releaseAt` の前でも新キャラが見える）
2. ユーザーが試験場で遊んで数値を詰める
3. 決まったら本番の `EVENTS` に入れる（開始日時・お知らせ・バナー）

試験場は、バベル試験場（`?lab=babel`）・チュートリアル試験場（`?lab=tutorial`）と同じく、**本番のセーブとクラウドに書かない**こと（`LAB_MODE` / `TUT_LAB` と同じガード）。

試験場でできてほしいこと:
- 新キャラ6体を、Lv・★（★5〜★10）・スキルLv（1〜10）・パッシブLv（1〜5）を選んで手持ちに入れられる
- クエスト1〜10層、EX1〜EX3、HELLを、日付に関係なく選んで戦える
- 既存のキャラも編成に入れられる（相性を確かめるため）

### 採点式についての注意

`tools/balance/power_lib.js` は、防御バフ・デバフ（`pdefUp` など、ポイント加算）を割合として読んでしまう。直るまでは、防御バフが入ったスキルの採点を信用しないこと。

## 4. 星刻特性（`MONSTER_PERKS`）

6体とも、企画の資料の表のとおり★6〜★10を入れる。**★6でスキル1、★7でパッシブ、★8でスキル2、★9で奥義、★10でコンセプト**の決まりで作ってある。テストは `tools/perk_test.js` に足す。`from` はイベントの `startAt` と同じにする（新キャラ自体が `releaseAt` で隠れているので、なくても困らない）。

## 5. 遺物（`RELICS`）

| ID（仮） | 名前 | ★ | 基本 | 効果 |
| --- | --- | --- | --- | --- |
| rel_hinomaru_touken | 日の丸桃剣 | 5 | `{ hp:85.4, atk:19.8 }` | `hp 0.15 無条件` / `atk 0.15 element:grass` / `skillDmg 0.165 mon:m171` |
| rel_hinomaru_hachimaki | 日の丸の鉢巻 | 4 | `{ hp:34.4, atk:21.6 }` | `atk 0.125 無条件` / `skillDmg 0.125 element:grass` / `pierce 0.125 element:grass` |

- 専用遺物は `exclusiveRelicForMon` で引けるようにする（遺物ガチャの自動ピックアップに乗る）
- 鉢巻はガチャに出さない。**イベントショップで本体（200メダル×1）と重複（200メダル×4）を売る**。1・3・6・8・10層の初回クリアで遺物を配るのはやめ、その層もほかの層と同じ強化素材にする（`EVENT_RELIC_LAYERS` / `eventStageRelicReward`）
- `EVENT_ELEMENT_RELIC` は属性ごとに1つなので、`ev.relic` でイベントごとに配布遺物を指定できるようにする（ショップの `relic_dupe` もこれを見る）
- アイコンは `RELIC_ICON` に SVG を足す
- 2つとも `releaseAt` を書く（遺物ガチャ・遺物図鑑に日付の前は出ない）

## 6. イベント（`EVENTS`）

```js
{
  key: 'ev_momotaro',
  econV2: true,
  name: '（イベント名は未定）',
  pickup: 'm171',
  featured: ['m171', 'm172', 'm173', 'm174'],   // ★4の3体
  stageName: '鬼ヶ島',
  terrain: 'sea',
  element: 'grass',
  waveSizes: [3, 3, 4, 4, 5],
  escortPools: [
    { from: 1, list: [/* 鬼火・河童・猫又・カマイタチ・マンドラゴラ */] },
    { from: 5, list: [/* 鬼火・猫又・河童・アカオニ・アオオニ・天狗・のっぺらぼう */] },
    { from: 8, list: [/* アカオニ・アオオニ・天狗・雷獣・土蜘蛛・のっぺらぼう・牛鬼 */] },
  ],
  finalWave: ['m172', 'm173', 'm174', 'm88'],   // 新しい項目。ボス(モモタロウ)の後ろに固定で並べる。m88 = ウンディーネ
  tiers: [ /* 嵐呼ぶ神狼と同じ10段 */ ],
}
```

- **`finalWave` は新しい項目。** `buildEventStages` は今、最終ウェーブを「ボス＋護衛プールから順番」で作っている。`finalWave` があればそちらを使うように直す（★は護衛と同じ `t.star`）
- メダル（`EVENT_MEDAL`）・称号（`EVENT_TITLES`）・色（`EVENT_THEME`）・イベントショップも、前回と同じ形で足す
- 話の筋: 鬼退治を終えたモモタロウ一行が、鬼ヶ島で腕試しの相手を待っている

## 7. EX（`EVENT_EX` / `EVENT_EX_RULES`）

### 段

| 段 | lv | boss | mob | sk | 追加ルール |
| --- | --- | --- | --- | --- | --- |
| EX1 | 80 | 6 | 4 | 8 | なし |
| EX2 | 200 | 8 | 5 | 10 | なし |
| EX3 | 300 | 10 | 6 | 12 | なし |
| **HELL** | 300 | 10 | **10** | 12 | 敵のモモタロウ 最大HP+100%（`who:{ ref:'m171' }, side:'enemy', stat:{ hp:1.0 }`） |

- 各段10体まで: モモタロウ / イヌ・サル・キジ / 牛鬼・ウンディーネ / アカオニ・アオオニ・天狗・雷獣
- 最終ウェーブは「モモタロウ・イヌ・サル・キジ・ウンディーネ」。前後の配置（`:front` / `:back`）を必ず書く
- **主役以外の★5は入れない**

### 共通ルール（`EVENT_EX_RULES.ex_momotaro`）

```js
rules: [
  { who:{ species:'hume' },  side:'ally', stat:{ str:0.25, hp:0.25 },   label:'ヒュームの味方 STR・HP+25%' },
  { who:{ species:'beast' }, side:'ally', stat:{ str:0.25, hp:0.25 },   label:'ビーストの味方 STR・HP+25%' },
  { who:{ species:'demon' }, side:'ally', stat:{ str:-0.25, hp:-0.25 }, label:'デーモンの味方 STR・HP-25%' },
  { side:'enemy', stat:{ hp:0.5 }, label:'敵 最大HP+50%' },
  { side:'ally', dmgDealt:0.6, whenTarget:'lowHp50', label:'HPが50%以下の敵へ 与ダメージ+60%' },
  { side:'enemy', dmgDealt:0.4, atk:'phys', label:'敵 物理ダメージ+40%' },
]
```

- `whenTarget:'lowHp50'` が使えるかは確認する（ガイドの表では `when` に lowHp50 がある）

### HELL（4段目）

- 名前は「HELL」（画面では「鬼ヶ島・HELL」）。解放条件は EX3 クリア
- `EX_FIRST_CLEAR_CRYSTAL` を `[100, 200, 400, 500]` にする（クリアで石）。新バトルシステムのお試しのお礼（`BATTLE_V2_CLEAR_CRYSTAL_EX`）は α0.5 でなくなるので、4段目は要らない。**HELLを★3でクリアすると、称号と、主役の入った派手なアイコンフレーム**（イベントミッションの `ex3star` と同じ形で `hellstar` を足す）
- `EX_MOB_SOUL_RATE` に4段目を足す。EX3と同じ率
- EXを3段前提にしている箇所（ミッション・画面・`tools/event_ex_test.js`）を探して直す
- 雑魚★10は `EX_STAR_CAP = 10` で通る。星刻特性が敵にも付くこと（EXは★10まで）を確認する

## 8. 測る

試験場ができたら、`tools/` のハーネスで次を測って企画の資料に書く。

- クエスト10層: 3パーティ（高レア / 基本B / 気絶）で各層40戦
- EX1: Lv70・★4・スキルLv3・遺物ルーンなし（総BP約11,000）で60〜90%
- EX3: Lv250・★5・スキルLv10・遺物★5Lv80＋ルーンⅧ金×2（総BP約74,000）で30〜70%、1戦12ラウンド以下
- HELL: Lv300・★10・スキルLv10・パッシブLv5・遺物とルーンを積んだ編成で10〜40%（能力倍率は1.0から）
- 新キャラ: お供と組んだときと、1体だけのときのダメージ
