# 星刻特性の見直し（★5・12体）

Oct 6, 2026 · @ねぎらーめん

新しいルール（`docs/design/PUイベントの企画の流れ.md`）で、既存の★5の星刻特性を並べ直した案。**★6 スキル1 → ★7 パッシブ → ★8 スキル2 → ★9 奥義 → ★10 コンセプト**。素のステータスアップだけの段はなくし、Lvで伸びる数値（威力・効果量）は上げない。中身は、できるだけ今の星刻（実装ずみ・確定ずみ）を活かして段を入れ替えた。

- スキルの説明は、今のゲームの表示のまま（新しい書き方への置き換えは別）
- 「今の星刻」: 九尾の狐・タイタン・フェンリル・アバドンは実装ずみ（`MONSTER_PERKS`）。ほかの8体は確定・未実装（`docs/design/星刻特性_★5の8体.json`）
