# 次回イベント案（豊穣の女神・フレイヤ）

10/13ごろ〜10/26ごろの「豊穣の女神」イベント（「桃太郎」と2本同時）に出すキャラの案。作り方は `docs/design/PUイベントの企画の流れ.md` に合わせる。**「仮」と書いたものは未決定。**

## 決まっている前提

- フレイヤ: ★5・**土**・サポーター。北欧神話の豊穣と愛の女神。★5の土は3体ともタンクなので、土のサポーターは初めて
- 同時ピックアップの★4は2体: **フレイ**（★4・土。フレイヤの双子の兄）と **ヒルディスヴィーニ**（★4・光・タンク・ドワーフ。フレイヤが乗る、ドワーフが作った猪）
  - ★4の光のタンクは今いない（★2にセラミックゴーレム・スカラベがいるだけ）
- フレイヤはパッシブで通常攻撃をしない。代わりに、HPの割合が一番低い味方を回復する
- **攻撃はみんな魔法**（物理寄りのキャラが多いため）
- お供は単体で完結させる。相性は「回復を受けたとき」「HPが満タンのとき」など、誰と組んでも満たせる条件で作る

## キャラ

**表の読み方**: スキル・奥義の数値は「Lv1→Lv10」（上限10）。威力・回復量・効果量はLv10で1.5倍（Lv1→10を9等分）。ターン数は、味方への付与がLv5とLv10で+1ずつ、敵への付与がLv10で+1（上限5ターン）。通常攻撃・挑発・回数・CT・SP・確率はLvで変わらない。**パッシブの数値は「Lv1→Lv5」**（上限5、Lv5で1.5倍。`docs/提案資料/パッシブLvの区切り見直し.md`）。Lv1の値は10の倍数か偶数にそろえ、最大も整数になるようにしている。採点は Lv1 の値で、そのレアリティの予算に対する割合。

**自分のパッシブで復活したときは「倒れた」に数えない**（★2・★3の「味方が1体も倒れない」に触れない）。ほかの味方による蘇生は「倒れた」に数える。

**星刻特性の順番**: ★6 スキル1 → ★7 パッシブ → ★8 スキル2 → ★9 奥義 → ★10 そのキャラのコンセプトの大きな強化。Lvで伸びる数値（威力・効果量）は星刻で上げず、対象・回数・CT・ターン数・条件・追加効果で強くする。

用語は `docs/名称置き換え資料.md` の「状態の名前」にそろえる（攻撃力上昇・攻撃力低下・加速・鈍化 など）。命中低下は「その敵の攻撃が外れる確率が上がる」状態（狙われた側の回避率に足される）。**物理防御・魔法防御・SPDの上昇・低下はポイント**（防御1ポイント＝受けるダメージ1%カット。加速・鈍化はSPDの足し算・引き算）。

フレイヤが持つ、着ると鷹に変身できる羽衣。首飾り（ブリーシンガメン）はスキル1の名前に使ったので、こちらにした。数値は「初期→最大」。

### 配布遺物の配り方（モモタロウイベと共通）

- 今までの「1・3・6・8・10層の初回クリアで本体と重複を配り、全層クリアで完凸」はやめる
- **イベントショップで、本体と重複を売る**

| 商品 | 価格 | 上限 |
| --- | --- | --- |
| 配布遺物（本体） | 200メダル | 1回 |
| 配布遺物（重複） | 200メダル | 4回 |

- 遺物の完凸は「凸4回」（本体＋重複4個＝5個）。モンスターの★10とは別の仕組み。凸1回ごとに+10%（`RELIC_MAX_DUPE_USE = 4`）。遺物スキルLvは別で、上限10（効果の数値が「初期→最大」になる）
- 全部買うと1,000メダル（ステージ10をイベントボーナス最大で約10周ぶん）
- 1・3・6・8・10層の初回クリアで配っていた分は、ほかの層と同じ強化素材（霊素鉱・コア）にする
- 実装メモ: 今のショップの「重複」は `EVENT_ELEMENT_RELIC[ev.element]` を売るので、土ならアトラスの重石になってしまう。イベントごとに配布遺物を指定する項目（例: `ev.relic`）を足す
