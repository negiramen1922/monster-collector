10/13ごろ〜10/26ごろの「豊穣の女神」イベント（「桃太郎」と2本同時）に出すキャラの案。作り方は `docs/design/PUイベントの企画の流れ.md` に合わせる。**「仮」と書いたものは未決定。**

## 決まっている前提

- フレイヤ: ★5・**土**・サポーター。北欧神話の豊穣と愛の女神。★5の土は3体ともタンクなので、土のサポーターは初めて
- 同時ピックアップの★4は2体: **フレイ**（★4・土。フレイヤの双子の兄）と **ヒルディスヴィーニ**（★4・光・タンク。フレイヤが乗る猪）
  - ★4の光のタンクは今いない（★2にセラミックゴーレム・スカラベがいるだけ）
- フレイヤはパッシブで通常攻撃をしない。代わりに、HPの割合が一番低い味方を回復する
- お供は単体で完結させる。相性は「回復を受けたとき」「HPが満タンのとき」など、誰と組んでも満たせる条件で作る

## フレイヤ（★5・土・サポーター・セレスティア）

ステータス案（仮）: HP270・STR44・物理防御6・魔法防御9・SPD46。科はミスティック科（仮）。

| 枠 | 名前 | 効果 | 採点（★5の予算比） |
| --- | --- | --- | --- |
| 通常攻撃 | （なし） | パッシブで回復に置き換わる | |
| スキル1 (CT3) | ブリーシンガメンの輝き | 自分以外でSTRが一番高い味方2人に、STR+30%（2ターン） | 24点 / 26.4 = 91% |
| スキル2 (CT4) | 黄金の涙 | HPの割合が一番低い味方を回復（回復量250%）。3ターン、毎ターン最大HPの5%を回復 | 30点 / 32.4 = 91% |
| パッシブ | 豊穣の恵み | 通常攻撃をしない。代わりに、HPの割合が一番低い味方を回復（回復量130%） | |
| 奥義 (SP100) | フォールクヴァングの実り | 味方全体を回復（回復量250%）。味方全体に最大HPの20%のシールド（2ターン） | 69点 / 66 = 104% |

- 名前の由来: ブリーシンガメンはフレイヤの首飾り。黄金の涙は、フレイヤが流すと金になる涙。フォールクヴァングはフレイヤの館（戦死者の半分を迎える）

| 星刻 | 特性 |
| --- | --- |

## フレイ（★4・土・ロールは未定・セレスティア）

### 元ネタ

北欧神話のヴァン神族の神。フレイヤの双子の兄。

| 要素 | 中身 |
| --- | --- |
| 司るもの | 豊穣・陽の光と雨・平和と繁栄。人々に実りを与える |
| 治める国 | アルフヘイム（光のエルフの国）の王 |
| 勝利の剣 | 持ち主が賢ければ、ひとりでに戦う剣 |
| 剣を手放した話 | 巨人の娘ゲルズに一目ぼれし、従者スキールニルに結婚の使いを頼む。その礼に勝利の剣を渡してしまう |
| 鹿の角 | 剣がないので、巨人ベリを鹿の角で討ち取った |
| ラグナロク | 剣がないまま炎の巨人スルトと戦い、倒れる（ゲームにスルトがいる） |
| 持ち物 | 金の毛の猪グリンブルスティ（暗闇でも光る）、折りたためる船スキーズブラズニル（いつも追い風が吹く） |

- **猪はヒルディスヴィーニとかぶるので使わない**（グリンブルスティは外した）
- 使える題材: 勝利の剣（ひとりでに戦う）、剣を手放した神、鹿の角、陽光と雨、アルフヘイム、スキーズブラズニル、スルトとの因縁
