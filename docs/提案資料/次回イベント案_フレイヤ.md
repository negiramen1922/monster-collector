## フレイヤ（★5・サポーター・セレスティア・属性は仮）

ステータス案（仮）: HP270・STR44・物理防御6・魔法防御9・SPD46（ホーリードラゴンはHP290・STR39・SPD41。回復役なので少し速くした）。科はミスティック科（仮）。

| 枠 | 名前 | 効果 | 採点（★5の予算比） |
| --- | --- | --- | --- |
| 通常攻撃 | （なし） | パッシブで回復に置き換わる | |
| スキル1 (CT3) | ブリーシンガメンの輝き | 味方全体のSTR+20%（3ターン） | 30点 / 26.4 = 114% |
| スキル2 (CT4) | 黄金の涙 | HPの割合が一番低い味方を回復（回復量250%）。3ターン、毎ターン最大HPの5%を回復 | 30点 / 32.4 = 91% |
| パッシブ | 豊穣の恵み | 通常攻撃をしない。代わりに、HPの割合が一番低い味方を回復（回復量130%） | |
| 奥義 (SP100) | フォールクヴァングの実り | 味方全体を回復（回復量250%）。味方全体に最大HPの20%のシールド（2ターン） | 69点 / 66 = 104% |

- 名前の由来: ブリーシンガメンはフレイヤの首飾り。黄金の涙は、フレイヤが流すと金になる涙。フォールクヴァングはフレイヤの館（戦死者の半分を迎える）
- 通常攻撃をしないので、ダメージは0。そのぶん回復とバフを★5らしく強めにしている

| 星刻 | 特性 |
| --- | --- |
| ★6 | 最大HP+15% |
| ★7 | 豊穣の恵み: HPが満タンの味方には、回復量の半分をシールドにする（回復の無駄を減らす） |
| ★8 | ブリーシンガメンの輝き: STRアップ 3 → 4ターン |
| ★9 | 黄金の涙: CT4 → 3 |
| ★10 | フォールクヴァングの実り: 1戦闘に1回、戦闘不能の味方1体をHP50%で復活させる（館が戦死者を迎える） |
