# 次回イベント案（豊穣の女神・フレイヤ）

Oct 5, 2026 · @ねぎらーめん

10/13ごろ〜10/26ごろの「豊穣の女神」イベント（「桃太郎」と2本同時）に出すキャラの案。作り方は `docs/design/PUイベントの企画の流れ.md` に合わせる。**「仮」と書いたものは未決定。**

## 決まっている前提

- フレイヤ: ★5・**土**・サポーター。北欧神話の豊穣と愛の女神。★5の土は3体ともタンクなので、土のサポーターは初めて
- 同時ピックアップの★4は2体: **フレイ**（★4・土。フレイヤの双子の兄）と **ヒルディスヴィーニ**（★4・光・タンク・ドワーフ。フレイヤが乗る、ドワーフが作った猪）
  - ★4の光のタンクは今いない（★2にセラミックゴーレム・スカラベがいるだけ）
- フレイヤはパッシブで通常攻撃をしない。代わりに、HPの割合が一番低い味方を回復する
- **攻撃はみんな魔法**（物理寄りのキャラが多いため）
- お供は単体で完結させる。相性は「回復を受けたとき」「HPが満タンのとき」など、誰と組んでも満たせる条件で作る

## キャラ

**表の読み方**: スキル・奥義の数値は「Lv1→Lv12」。威力・回復量・効果量はLvごとに+5%（Lv12で1.55倍）。ターン数は、味方への付与がLv5とLv10で+1ずつ、敵への付与がLv10で+1（上限5ターン）。通常攻撃・挑発・回数・CT・SP・確率はLvで変わらない。**パッシブの数値は「Lv1→Lv5」**で、`docs/提案資料/パッシブLvの区切り見直し.md` の案B（Lv5で1.5倍）で書いている。採点は Lv1 の値で、そのレアリティの予算に対する割合。

用語は `docs/名称置き換え資料.md` の「状態の名前」にそろえる（攻撃力上昇・攻撃力低下・加速・鈍化 など）。

### 配布遺物の配り方（モモタロウイベと共通）

- 今までの「1・3・6・8・10層の初回クリアで本体と重複を配り、全層クリアで完凸」はやめる
- **イベントショップで、本体と重複を売る**

| 商品 | 価格 | 上限 |
| --- | --- | --- |
| 配布遺物（本体） | 200メダル | 1回 |
| 配布遺物（重複） | 200メダル | 4回 |

- 遺物の完凸は「凸4回」（本体＋重複4個＝5個）。モンスターの★10とは別の仕組み。凸1回ごとに+10%（`RELIC_MAX_DUPE_USE = 4`）。遺物スキルLvは別で、上限10（効果の数値が「初期→最大」になる）
- 全部買うと1,000メダル（ステージ10をイベントボーナス最大で約10周ぶん）
- 1・3・6・8・10層の初回クリアで配っていた分は、ほかの層と同じ強化素材（霊素鉱・コア）にする
- 実装メモ: 今のショップの「重複」は `EVENT_ELEMENT_RELIC[ev.element]` を売るので、土ならアトラスの重石になってしまう。イベントごとに配布遺物を指定する項目（例: `ev.relic`）を足す

## 新しく作る仕組み

- 「自分以外でSTRが一番高い味方2人」を狙う対象（フレイヤのスキル1）
- 通常攻撃を回復に置き換えるパッシブ（フレイヤ）
- 「回復を受けるたび」のフック（ヒルディスヴィーニ）
- 使うたびに形が入れ替わるスキル（フレイのスキル1）と、次の形の表示
- クエストの最終ウェーブを固定する仕組み（`finalWave`。モモタロウイベと共通）
- 配布遺物をイベントごとに指定し、ショップで本体と重複を売る（`ev.relic`。モモタロウイベと共通）
- ステージ効果の新しい条件: `whenTarget:'strDown'`、`when:'notShielded'`
- エインヘリャル（新キャラ★2）の「1戦闘に1回の復活」
- 立ち絵: エインヘリャルとワルキューレ4人のぶんも要る（計8体）
- HELL（4段目）。モモタロウイベと共通
- 立ち絵: 3体とも未確認
