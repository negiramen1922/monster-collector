# スライムパラダイス

## スライム共通の決まり（今のスライム7体にそろえる）

今のスライム（アクア・モス・マグマ・ホーリー・ヴェノム・アイアン・シー）は、次の描き方で統一されています。新しい5体も必ずこれに合わせてください。

```
スライム共通:
顔（目・口）は描かない。
半透明でつやのあるゼリーの体。上にハイライト、下は地面に垂れて広がる。
体の中に「核」（丸い玉や、その子を表す小物）が透けて見える。
裾から雫が垂れる。体の中に小さな泡。
```

- 参考に並べるもの: シースライム（sprite 31・濃い青・中に赤い核と魚）、ホーリースライム（sprite 34・クリーム色・頭の上に金の輪）

## 1. キングスライム（★4・水・タンク）

スライムの王さま。大きな体で仲間をかばい、倒れても小さなスライム2体に分かれて戦い続ける。

```
ドット絵、256x256、透明背景、全身。
大きなスライム。ほかのスライムより一回り大きく、横に広い、どっしりした山形。
体は澄んだ明るい青のゼリー。シースライム（濃い青）より明るく、空色に近い。
頭のてっぺんに、少し傾いた金の王冠。王冠には赤い宝石。
体の中に、核として赤い大きな宝玉が透けて見える。
体の下半分に、赤いマントのような布が少しだけ巻きついている（王さまらしさ）。
裾から雫が垂れる。中に小さな泡。
顔（目・口）は描かない。
王冠を大きくしすぎない（体の5分の1くらい）。
```

## 1-2. ちびスライム（キングスライムの分身。戦闘中だけ出る）

キングが倒れると、2体に分かれて出てくる。図鑑には載せない。

```
ドット絵、256x256、透明背景、全身。
キングスライムをそのまま小さくした姿。画面の半分くらいの大きさで、下の方に寄せて描く。
体は同じ明るい青のゼリー。中に小さな赤い核。
頭の上に、小さな金の王冠のかけら（王冠の半分くらい）。マントは無し。
顔（目・口）は描かない。
```

## 2. アークエンジェルスライム（★4・光・シューター）

弱っていたアークエンジェルを飲みこんだスライム。体の中で神聖な力が高まり、光の属性に目覚めた。空から光の矢を雨のように降らせ、当たるたびに仲間を癒やす。

```
ドット絵、256x256、透明背景、全身。
白に近い淡い金色のゼリーのスライム。少し宙に浮いていて、裾の雫は下に光の粒になって落ちる。
体の中に、飲みこんだ天使が核として透けて見える：小さく丸まった天使の影と、光る羽根が数枚。
背中に、白い天使の翼が2対（4枚）。大きく広げる。
頭の上に、二重の金の光輪。
体のまわりに、細い光の矢が数本浮いている（先が下を向く）。
顔（目・口）は描かない。
ホーリースライム（クリーム色・光輪1つ・翼なし）と見分けがつくこと：翼4枚・光輪2重・中の天使の影が目印。
```

## 3. アーススライム（★3・土・タンク）

岩を背負った重いスライム。ねばつく体で殴ってきた相手の足を取り、ひと飲みにして動けなくする。

```
ドット絵、256x256、透明背景、全身。
茶色の泥のようなゼリーのスライム。にごっていて、ほかのスライムより透明感が低い。
背中（体の上）に、ごつごつした灰色の岩をいくつか背負っている。岩には苔が少し。
低く平たく、どっしりした体。裾は地面に広がって、粘り気のある糸を引く。
体の中に、核として琥珀色の丸い石が透けて見える。
足元に小石と土ぼこり。
顔（目・口）は描かない。
ゴーレムにはしない（あくまでスライムが岩を背負っている形）。
```

## 4. ウィンドスライム（★3・風・シューター）

風に乗ってふわふわ飛ぶ、軽いスライム。仲間が攻撃すると、その風に乗って一緒に攻撃する。

```
ドット絵、256x256、透明背景、全身。
薄い若草色〜ミント色の、軽く透けたゼリーのスライム。
地面から少し浮いていて、体は風になびいて片側に流れる、しずく形。
体の中に、核として小さなつむじ風（緑白の渦）が透けて見える。
体のまわりに、風の筋と、舞う木の葉が2〜3枚。
裾は地面につかず、細くたなびく。
顔（目・口）は描かない。
モススライム（濃い緑・苔と芽）と見分けがつくこと：色は薄く、透明感が高く、浮いている。
```

## 5. ゴールドスライム（★3・無・タンク）

金色に光る、めったに会えないスライム。体は硬く、逃げ足も速いが、急所をつかれると弱い。倒すとゴールドを多く落とす。

```
ドット絵、256x256、透明背景、全身。
ぴかぴかの金色のスライム。ゼリーというより、溶けた金属のようなつやのある体。
強いハイライトと、体のまわりにきらきらの光の粒。
体の中に、核として金貨が数枚重なって透けて見える。
裾の雫も金色。足元に金貨が1〜2枚落ちている。
少し前のめりで、今にも走って逃げ出しそうな姿勢。
顔（目・口）は描かない。
アイアンスライム（銀色）と見分けがつくこと：はっきりした金色・金貨の核が目印。
```

# ハロウィン

ハロウィンの夜の仲間たち。6体並べたときに、橙（かぼちゃ）・紫（夜）・緑（おばけの火）の色でまとまって見えるように。

## 6. ジャック・オ・ランタン（★5・炎・トリックスター）主役

かぼちゃを被り、ナイフを手にした女の子。ハロウィンの夜、いたずらの相手を探して町をかけ回る。ナイフで何度も切りつける、手数の多いいたずらっ子。

```
ドット絵、256x256、透明背景、全身の立ち姿。主役なので存在感を出す。
小柄な人間の女の子。頭にくり抜いたかぼちゃを被っている。
かぼちゃは顔の上半分まで深く被り、くり抜いた目と口の穴から橙の火の光がもれる。口元（あご・唇）は見えていて、いたずらっぽく笑っている。
服は黒と橙のハロウィンらしいワンピース。裾はぎざぎざ。黒いマント。
縞（橙と黒）のタイツ、先の丸いブーツ。
両手に小ぶりのナイフを1本ずつ、逆手に持つ。刃に橙の火がうっすら映る。
腰に小さなランタン（悪魔の残り火の炎が中に灯っている）。
足元に、舞う火の粉とかぼちゃの種。
走り出す直前の、軽やかで前がかりな姿勢。
こわくしすぎない。血は描かない。かぼちゃのお化けそのもの（体がかぼちゃ）にはしない。
```

## 7. ミミック（★4・土・トリックスター）

宝箱のふりをして待ち伏せる魔物。ふたを開けた者に、だれよりも先にかみつく。

```
ドット絵、256x256、透明背景、全身。
古い木の宝箱の魔物。金具は錆びた金色、木は焦げ茶。
ふたが大きく開いて、中に鋭い歯が並ぶ。中から長い赤紫の舌が垂れる。
ふたの内側の暗がりに、光る黄色い目が2つ。
箱の中に、金貨と宝石が少しだけ見える（おとりの財宝）。
箱の下から、短い獣の脚が4本生えて、今にも飛びかかる姿勢。
足元に土ぼこり。
グロテスクにしすぎない。ゲームらしい「宝箱の魔物」。
```

## 8. ヴァンパイア（★4・闇・アタッカー）

夜の貴族。血を吸って傷を癒やし、あふれた血を身にまとって守りにする。コウモリの群れに姿を変える。

```
ドット絵、256x256、透明背景、全身の立ち姿。
細身で背の高い、色白の青年貴族。
黒い燕尾服、赤い裏地の黒いマント（襟が高く立つ）。白いクラバット。
髪は黒、後ろへなでつける。目は赤。口元に小さな牙が見える。
片手を前に伸ばし、その手のまわりに赤い血の霧が渦を巻いて、薄い盾の形になっている。
マントの裾が、何匹かのコウモリに崩れかけている。
背後に大きな赤い月。足元に黒い霧。
血しぶきは描かない。血は「赤く光る霧」として描く。
```

## 9. パンプキンヘッド（★3・炎・サポーター）

ジャックの子分の、かぼちゃのおばけ。頭の中の火でみんなを照らし、ポケットのお菓子を仲間に配る。

```
ドット絵、256x256、透明背景、全身。
頭が大きなかぼちゃのおばけ。かぼちゃには三角の目とぎざぎざの口がくり抜かれ、中から暖かい橙の火の光がもれる。
体は小さく、つる草でできた細い体に、ぼろぼろの緑のポンチョ。
片手にキャンディ（包み紙つき）を高く掲げ、もう片方の手でお菓子の入った袋を抱えている。
頭のてっぺんにくるりと巻いたつると葉っぱ。
足元に、包み紙のお菓子が数個。
こわくしない。親しみやすい子分らしい姿。
ジャック（女の子・ナイフ）と並べたとき、親分と子分に見えること。
```

## 10. フランケン（★3・雷・タンク）

雷の力で動く、つぎはぎの大男。殴られるほど体に電気がたまり、ためた電気を一気に放つ。

```
ドット絵、256x256、透明背景、全身の立ち姿。
大柄でがっしりした人造の大男。肌は灰色がかった緑。
顔と腕に縫い目のつぎはぎ。首の両側に金属のボルト。
頭は平らで、黒い短髪。
ぼろぼろの黒いコートと、つんつるてんのズボン。重い鉄の靴。
両手の拳を握り、腕から首のボルトにかけて青白い電気がばちばちと走る。
足元に電気の火花と、ちぎれた鎖。
キョンシー（青い服・お札・中華風）とはまったく別の見た目にする。
こわくしすぎない。大きくて頼れる用心棒の雰囲気。
```

## 11. 黒猫（★3・闇・トリックスター）

魔女の使い魔の黒猫。目の前を横切って相手を不吉にし、ねらいを外させる。

```
ドット絵、256x256、透明背景、全身。
四本足の、すらりとした黒猫。服は着ない（ふつうの猫の体型）。
毛は黒だが、輪郭と毛並みのハイライトを紫で入れて、暗い背景でも形が分かるようにする。
目は明るい紫で、細く光る。
首に紫のリボンと、三日月の形の小さな鈴。
小さな魔女の帽子（紫）を、片耳にちょこんと引っかけている。
しっぽは長く、先がくるりと巻く。
歩いて横切る途中の、横を向きかけた姿勢。
足元に、紫の小さな星の粒。
ケットシー（黒猫・服とマントを着て二本足で立つ）と見分けがつくこと：四本足・服なし・魔女の帽子と三日月の鈴が目印。
猫又（灰色・しっぽが2本）とも見分けがつくこと。
```
