# 経済見直し 実装指示書

この1枚で実装できるように書いています。対象は `index.html`（単一ファイル）。

- 抽出: `tools/extract.py` → `tools/game.js` + `tools/mons.json`
- node テストは **`tools/` から実行**（`node tools/xxx_test.js` ではなく `cd tools && node xxx_test.js`）
- Playwright は `CHROMIUM_PATH=/opt/pw-browsers/chromium`

## 落としどころ（これを満たせば完成）

|---|---|
| 月の石（恒常+イベント+競技+深淵） | **39,600石相当** |

## ② ステージの石

### メインクエスト

`index.html` の `firstClear` 生成部（`rec, stamina: t.key === 'tu' ? 0 : 10, ...` の行）。

```js
// 現行: firstClear: t.key === 'tu' ? [100,150,3200][i] : isBoss ? 300 : 50 + i * 5
// 新:   firstClear: t.key === 'tu' ? [100,150,3200][i] : isBoss ? 100 : 30
```

ハードの `firstClear: src.firstClear ? src.firstClear * 2 : 0` を **`* 1`（＝通常と同じ）** にする。

// 現行

// 新
const TIER_STAR_CHESTS = [{ stars:10, crystals:200 }, { stars:20, crystals:300 }, { stars:30, crystals:500 }];

| 1クエスト（10本）のクリア石 | 1,160（ハード2,320） | **440** |
| ★箱 | 1,600 | **1,000** |
| 1クエスト ★3全クリア | 2,760（ハード3,920） | **1,440** |

チュートリアルは**5本に作り直す**（別作業・`docs/提案資料/チュートリアル作り直し.md`）。

**`isBoss ? 100 : 30` の側には触らない**（マージ時はこの1行だけ手で合わせる）。

## ⑦ 既存プレイヤーへの対処

### 実績は途中から反映でよい

`ACHIEVEMENTS` の `value()` は**その時点の統計と所持状態を読む**だけなので、新しい実績を足せば既存プレイヤーでも自動で判定される。すでに条件を満たしている段は**その場で受け取れる**。

**遡って反映されるもの**（統計か所持状態がすでにある）

モンスターを集める／★5を集める／探索で仲間にする(`befriend`)／星刻(`promote`)／★Nを育てる／LvNを育てる／LvNの遺物／TierNのルーン／メインのボス(`clearedStages`)／メインの星(`stageStars`)／探索N回(`stageClear`)／育成N回(`dungeonClear`)／深淵N階(`abyssFloor`)／ガチャN回(`gachaPull`)／テイマーランク（状態から計算）

**0から始まるもの**（統計を新しく足す必要がある）

ルーンを合成する(`runeFuse`)／PVPで勝つ(`pvpWin` — 既存の `pvpBattle` は勝敗を分けていない)／イベントを完走する／EX3を★3でクリア／総力戦／封印戦／N日ログイン(`loginDays`)

この6つは**0スタートで割り切る**。遡れないことを実装時にお知らせの文面に書く。

### 下がるものの補填

α期のお約束（「影響が出る変更のときは星結晶でしっかりお返しします」）に沿う。既存プレイヤーから見た増減はこう。

| 下がる | 上がる |
|---|---|
| デイリー 270→150石（**-3,600石/月**） | ウィークリー 1,300→1,400石/週（+428石/月） |
| ミッションのゴールド全廃（-578,571G/月） | 実績 11,000→23,550石（**+12,550石**、既存ぶんは即受け取り） |
| 黄金の洞窟 -30% | かぶりソウル **★5で150→500（PU 300→1,000）** |
| 霊素工房の霊素核 -50% | 無形のソウル・無形の共鳴石 **1回あたり1.95→6.00個** |
| ★箱の未受け取りぶん（1,600→1,000石） | 霊素工房の霊素鉱 **2倍** |
| イベント・ステージの石 | |

**実績の差分12,550石が実質の補填**になる。それに加えてプレゼントボックスで一律配布する。

| | 量 | 理由 |
|---|---|---|
| 星結晶 | **3,000石** | デイリーの下げぶん（約1ヶ月弱） |
| 無形のソウル | **300個** | ソウル表の改定前に使ったぶんのお返し |
| 霊素核TierI | **30個** | 工房の核を半分にしたぶん |

すでに★4・★5を育てていた人は `SOULS_TO_NEXT` の合計が上がる（★4 3,900→4,000 / ★5 4,800→5,000）ので、**その差分は不足ぶんのソウルとして個別に配るか、無形のソウル300個でまとめて見る**。後者で足りる見込み。

## ⑨ 未実装のコンテンツ（別作業）

**総力戦・封印戦・バベル**はまだ無い。経済上は月10,000石（総力戦5,000 + 封印戦5,000）を担う前提なので、**入るまでは月29,600石＝天井27日**になる。

- 総力戦 / 封印戦: ランキング制。基礎4,000 + 順位報酬（1位+3,000 / 10位以内+2,000 / 100位以内+1,000）で平均5,000石。隔週で交互に開催して月1回ずつ。
- バベル: エンドコンテンツ。リセットなしの初回クリア報酬のみ、階層ごとに500〜1,000石。
