# 星刻特性の見直し（★4・星刻が実装ずみの4体）【決定・実装ずみ】

Oct 6, 2026 · @ねぎらーめん

★5と同じルール（**★6 スキル1 → ★7 パッシブ → ★8 スキル2 → ★9 奥義 → ★10 コンセプト**）で、星刻が実装ずみの★4（スルト・ブロック・ロキ・牛鬼）を並べ直した案。ほかの★4（30体）にはまだ星刻がない。

- スキルの説明は、今のゲームの表示のまま
- 4体とも実装ずみなので、入れ替えるときはお知らせで説明する

## スルト（★4・炎・アタッカー・ドワーフ）

ステータス: HP204・STR63・物理防御6・魔法防御5・SPD45

**コンセプト**: 炎の巨人。やけどを撒き、やけどの敵を焼き尽くすアタッカー。ラグナロクで世界を焼く。

| 枠 | 名前 | 今の効果 |
| --- | --- | --- |
| 通常攻撃 | 炎の大剣 | 威力100% |
| スキル1 (CT3) | 灼熱の薙ぎ | 威力150%。50%でやけど |
| スキル2 (CT4) | 巨人の怒り | STR+30%。攻撃に40%でやけどを付ける |
| パッシブ | 溶岩の肌 | やけどにかからない。攻撃してきた相手を30%でやけどにする |
| 奥義 (SP110) | ムスペルの業火 | 威力220%。やけど状態の相手には威力50%の追加攻撃 |

| ★ | 今の星刻 | 新しい星刻 |
| --- | --- | --- |
| ★6 スキル1 | やけど状態の敵への与ダメージ+10% | 灼熱の薙ぎ: 敵前衛全体 → 敵全体 |
| ★7 パッシブ | ムスペルの炎: 自分が攻撃した相手も30%でやけどに | 溶岩の肌: 自分が攻撃した相手も30%でやけどにするようになる |
| ★8 スキル2 | やけど状態の敵が3体以上いるとき 与ダメージ+15% | 巨人の怒り: 攻撃でやけどを付ける確率 40% → 70% |
| ★9 奥義 | 灼熱の薙ぎ: 敵前衛全体 → 敵全体 | ムスペルの業火: やけど状態の敵への追加攻撃が1回 → 2回 |
| ★10 コンセプト | ムスペルの業火: やけど状態の敵への追加攻撃が2回になる | **世界を焼く炎の巨人**: やけど状態の敵への与ダメージ+20%（すべての攻撃）。やけど状態の敵が3体以上いるときは、さらに+15%。理由: 戦場を焼くほど強くなる |
