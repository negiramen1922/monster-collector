## 読み方

**表の読み方**: スキル・奥義の数値は「Lv1→Lv10」（上限10）。威力・回復量・効果量はLv10で1.5倍（Lv1→10を9等分）。ターン数は、味方への付与がLv5とLv10で+1ずつ、敵への付与がLv10で+1（上限5ターン）。通常攻撃・挑発・回数・CT・SP・確率はLvで変わらない。**パッシブの数値は「Lv1→Lv5」**（上限5、Lv5で1.5倍）。Lv1の値は10の倍数か偶数にそろえ、最大も整数になるようにしている。

**採点**: `tools/balance/power_lib.js` の採点式で Lv1 の値を測り、そのレアリティの予算に対する割合を書いた（スキル: CT2 18 / CT3 22 / CT4 27 に ★3 ×1.0・★4 ×1.1・★5 ×1.2。奥義: 重さ1 35 / 重さ2 45 / 重さ3 55 に ★3 ×1.0・★4 ×1.15・★5 ×1.3）。スキルは85〜115%、奥義は100〜130%に収めた（ジャックのスキル1だけ、わざと低くした）。
- 採点式は**防御の上昇（ポイント）と、最大HPの○%の回復を正しく数えない**（キャラ設計のルール 4章）。この2つが入るものは手で計算した（防御は「10ポイント・1ターンで1.5点」、最大HPの○%回復は「○点×対象の係数」）。「強化を奪う／なければ混乱」のような分かれる効果も手で足した。手で計算したものには「手」と書いた

**奥義の必要SP**: 「重さ×ロール」の表の値をそのまま書いた（`docs/提案資料/奥義SPの見直し.md`。アタッカー・トリックスター: 重さ2 80 / 重さ3 100、サポーター: 重さ3 80、タンク: 重さ1 40）。

**自分のパッシブで復活・踏みとどまったときは「倒れた」に数えない**（★2・★3の「味方が1体も倒れない」に触れない）。ほかの味方による蘇生は「倒れた」に数える。

**星刻特性の順番**: ★6 スキル1 → ★7 パッシブ → ★8 スキル2 → ★9 奥義 → ★10 そのキャラのコンセプトの大きな強化。Lvで伸びる数値（威力・効果量）は星刻で上げず、対象・回数・CT・ターン数・条件・付与率・追加効果で強くする。

用語は `docs/名称置き換え資料.md` の「状態の名前」にそろえた。**物理防御・魔法防御・SPDの上昇・低下はポイント**。命中低下は「その敵の攻撃が外れる確率が上がる」状態。

### HELL の目標と測り方

**目標（ユーザーの方針）**: イベント組 育ちきりで100%・★5中心 育ちきりで70%くらい・それ以外は勝ちにくい（★4中心などは70%より低くてよく、育ちきっていない編成は勝てなくてよい）。**数値は試験場で詰める**（上の「測り始めの値」から）。

- 測り方は鬼ヶ島の指示書 8-1〜8-3 と同じ（試験場と同じ道・ルーンなし・遺物は合う★5を自動。育ちきり＝★10・Lv300・スキルLv10・パッシブLv5・★5遺物 Lv200/遺物スキル10/4凸で各60戦。少し下＝★9・Lv280・スキルLv10・パッシブLv4・★5遺物 Lv150/遺物スキル8/3凸で各40戦）
- 編成（案）: イベント組＝ジャック・ミミック・ヴァンパイア・パンプキンヘッド・フランケン / ★5中心1＝リヴァイアサン・フェンリル・アバドン・九尾・ホーリードラゴン / ★5中心2＝タイタン・フェンリル・バハムート・九尾・ウンディーネ / ★4中心＝牛鬼・ハティ・スコル・ウンディーネ・ロキ
- イベント組のジャックは専用遺物（遺物スキル10＝スキル1がCT1）を付けた形で測る。遺物の自動選びが専用遺物を選ぶかを確かめる
- 上げ下げの道具: `power`、敵 与ダメージ、敵のジャックのHP
