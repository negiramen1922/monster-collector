# 凸ボーナス案（★5キャラ）

Sep 26, 2026 · @ねぎらーめん

## 方針

★6〜★10で1段ずつ、キャラ固有の効果が増えていきます。どれも今あるスキルやパッシブの「らしさ」を伸ばす条件付きの効果で、★上げの報酬に数値以外の手ざわりを足すのが狙いです。

**段ごとの役割**

| ★ | 役割 | 中身の例 |
| --- | --- | --- |
| ★6 | 得意な場面を少し伸ばす | 条件付きの与ダメ・被ダメ補正（+10%前後） |
| ★7 | パッシブの幅を広げる | 発動回数・発動条件・発動タイミング・上限の回数 |
| ★8 | 新しい条件の効果を足す | 条件付きで+10〜15% |
| ★9 | スキル1つの形を変える | 効果ターン数・対象・ヒット数・追加効果・CT |
| ★10 | そのキャラだけの決め技 | 挙動が1つ変わる(必殺技の追加効果など) |

**スキルLvとかぶらないように**: スキルLv・パッシブLvで伸びる数値（威力・付与率・スキルやパッシブの効果量）は、凸ボーナスでは上げません。威力は1Lvごとに+5%（Lv12で×1.55）伸び、付与率は80%が上限なので、同じ種類を凸で足すと「スキルLvと同じもの」になるか、付与率は上限で腐ります。代わりに、スキルLvでは変わらない「回数・条件・ターン数・対象・追加効果」を増やします。

- 5段をすべて足しても、得意な場面で+40〜50%ほどに収めます。★10とルーンがすでに大きいので、凸ボーナスは「強さの上乗せ」より「使い方の広がり」を優先します。
- 効果はすべて、今の戦闘の仕組み(ダメージ・会心・被ダメージ・回復量の補正、ターン開始・撃破・会心・被弾などのタイミング)で作れるものに限っています。新しい仕組みが要る案は入れていません。
- 数値は目安です。確定した分から実装し、戦闘のシミュレーションで強さを確かめてから出します。
