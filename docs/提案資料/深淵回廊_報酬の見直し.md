# 深淵回廊 報酬の見直し（案）

Oct 20, 2026 · @ねぎらーめん

「次のシーズンから報酬を増やす」（2026-10-20 ユーザー）。深淵回廊は2週間ごとのシーズン制で、**各階の初回報酬だけ**（シーズンごとに受け取り直せる）。スタミナを使わないので、上限のない報酬は置かない（経済の単価表 3章）。到達した階までしか取れないので、1階ごとの報酬を増やしても上限はある。
