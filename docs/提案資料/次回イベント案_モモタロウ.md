# 次回イベント案（モモタロウ）

Oct 5, 2026 · @ねぎらーめん

10/13ごろ〜10/26ごろの「桃太郎」イベントに出すキャラの性能案です。index.html にはまだ入れていません。

## 決まっている前提

- モモタロウ: ★5・**草**・アタッカー・ヒューム。**HP寄り**のステータス（草の★5は初。草のアタッカーもモススライム★1・マンイーター★3・アラクネ★4の3体だけ）
- イヌ・サル・キジ: 3体とも**ビースト**。イヌはSTR寄りのアタッカー、サルは回避タンク、キジはシューター
- アカオニ・アオオニ: ★3・デーモン（アヤカシ科）。イベントクエストとEXで敵として出す。**性能はこの案で決定**
- お供は**3体とも★4**。属性はイヌ土・サル雷・キジ風で決定（★4の空き枠には無理に合わせない）
- **お供・オニは単体で完結させる。** 相性は「STRアップ中」「バフを受けている間」「味方のデーモンの数」など誰でも満たせる条件で作り、モモタロウやきびだんごを名指しで前提にしない（モモタロウがいると条件を満たしやすい、という形にとどめる）
- 星刻特性は**段ごとの役割を使わない**（手本は `docs/design/星刻特性_★5の8体.json`）

## 条件つきダメージアップのルール

**上がる量 = 条件の段階 × どの攻撃に乗るか × だれに乗るか**（5%単位に丸める）

| 条件の段階 | 例 | 値 |
| --- | --- | --- |
| ほぼいつも満たす | 自分のシールド中、いつも狙う後衛、自分より遅い敵（SPDの高いキャラ） | 10% |
| 自分で作れる | 自分で付けたやけど・デバフ、きびだんご中、編成で決まる条件（ビースト2〜3体・味方のデーモンの数） | 15% |
| 敵や状況しだい | デーモン、HPが50%以下、HPが70%以上 | 20% |
| 満たしにくい | 拘束・気絶、きつい編成条件（ビースト4体） | 30% |

| どの攻撃に乗るか | 倍率 |
| --- | --- |
| すべての攻撃 | ×1 |
| 通常攻撃だけ | ×1.25 |
| スキル1つだけ／必殺技だけ／パッシブの追加攻撃だけ（追撃・反撃など） | ×1.5 |

| だれに・いつ | 倍率 |
| --- | --- |
| 自分だけ | ×1 |
| 味方全体 | ×0.5 |
| スキルや必殺技で付く、数ターンだけのもの | ×1.5 |

- タンク・サポーターは1つ上の段階の値を使う（上限30%）。STRが低く、同じ%だと伸びが小さいため（リヴァイアサン★6のシールド中+20%がこれ）
- ★10は表の外でよい（決め技）
- 既存で外れているのは九尾★6（やけど+10% → ルールでは15%）

スキルの威力は `tools/balance/power_lib.js` の採点で、スキルは予算の85〜115%、必殺技は100〜130%に収めた（予算 CT3 22 / CT4 27 / SP100 55。★3 ×1.0 / ★4 ×1.1 / ★5 ×1.2）。

## 新しい状態「きびだんご」

- 3ターン、STR+20%
- ビーストなら、さらにSTR+15%・SPD+10%。付いたときにSP+15
- **すでにきびだんごが付いている味方には付けない**（付け直し・延長はしない）。付いていない味方の中から選ぶ

## 新しく作る仕組み

- 状態「きびだんご」（ビーストかどうかで効き方が変わる）
- 「自分以外でSTRが一番高い味方」を狙う対象（今の `allyTop` は自分も入るので、自分を外す形が要る）
- バフを奪う（今あるのは「はがす」`dispelBuff` だけ）
- 回避したときのフック（サルの反撃と会心率の積み上げ）（回避の上限は今のコードで95%。サルは最大50%なので届かない）
- 「各ウェーブの最初の攻撃」の判定（イヌ★7）
- デーモン（種族）を条件にした与ダメージアップ
- 立ち絵: サル・アカオニ・アオオニ（モモタロウ・イヌ・キジはリポジトリ直下に dreamina 画像あり）
