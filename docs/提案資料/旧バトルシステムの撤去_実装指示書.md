# 旧バトルシステムの撤去 実装指示書

Oct 6, 2026 · @ねぎらーめん

新バトルシステムを定着させ、旧バトルシステムをなくす（2026-10-06 決定）。今は設定の「新バトルシステム」で新旧を切り替えられる（`STATE.battleV2`、既定は新）。これをやめて、**いつでも新の動き**にする。

`docs/提案資料/実装の段取り.md` の第1段に入れる。奥義SP（第1段のA）で `ultSpCostFor` を触るので、**A と同じ作業の中で、A の前に入れる**のがよい。

---

## 1. 変えること

### 1-1. 切り替えをなくす

- `battleV2()` を使っている22か所を、新の側だけ残して書き直す（`battleV2()` が true のときの式だけにする）。最後に `battleV2()` 自体を消す
- 設定画面の「新バトルシステム」の切り替えと、その下の説明を消す
- `STATE.battleV2` は読まなくなる。古いセーブで `false` になっていても、新で動く（セーブから消してよい）
- PVP・深淵回廊の「新バトルシステムでのみ挑戦できます」のチェックを消す

### 1-2. 旧のためだけの値を消す

`battleV2()` で分けていた旧の側の値。ほかで使っていなければ消す。

| 旧 | 新（残す） |
| --- | --- |
| HPの倍率 1 | `BATTLE_V2_HP_SCALE`（2） |
| `SHIELD_CAP_RATIO`（0.5） | `BATTLE_V2_SHIELD_CAP`（1.0） |
| BPのHPの重み 0.6 | `BATTLE_V2_BP_HP`（0.3） |
| `SP_ON_HIT` / `SP_HIT_CAP_PER_ROUND` | `spFromDamage` / `BATTLE_V2_HIT_CAP` |
| `SP_ON_KILL` | `BATTLE_V2_SP_KILL` |
| スキルの開幕CT・スキル2の再CT+1 | 開幕CT0・順番に使う |
| 敵Lvを敵ごとに書く形 | `waveEnemyLv` |

- 名前の `BATTLE_V2_` は、残すなら残してよい（消すと差分が大きくなる）。消すかどうかは作業する人が決めてよい
- 奥義の必要SPのロール補正（`BATTLE_V2_ULT_ADJ`）は、第1段のAでなくなる

### 1-3. 「新バトルシステムのお試し」のお礼（**決めてもらう**）

今は、新バトルシステムでステージを初めてクリアすると、**1回だけスタミナ0で挑めて、お礼の星結晶**がもらえる（メイン10・イベント20・EX 100/300/500。`STATE.v2Cleared` で記録）。新旧の切り替えがなくなると、「お試し」の意味がなくなる。

- 案A: **やめる**。撤去と同時に、スタミナ0と星結晶をなくす。まだもらっていないステージのぶんは配らない
- 案B: **期限を決めてやめる**。撤去のお知らせで「○/○まで」と期限を出し、それまではスタミナ0とお礼を残す。期限を過ぎたらなくす
- 案C: **残す**。「ステージを初めてクリアしたら、スタミナ0＋星結晶」を、ふつうの初回クリア報酬として続ける

EXの初回クリアは、今は `EX_FIRST_CLEAR_CRYSTAL`（100/200/400）とこのお礼（100/300/500）の**両方**が出ている。HELLの4段目をいくつにするかは、ここの決め方で変わる（案A・Bならお礼の4段目は要らない）。

### 1-4. お知らせ

- 「新バトルシステムが正式になりました。旧バトルシステムには戻せなくなります」
- お試しのお礼をどうするか（1-3）

## 2. テスト

- `tools/battle_v2_test.js`: 新旧の切り替えを見ている所を消し、新の値だけを見る形にする
- `tools/dungeon_entry_test.js`: 深淵の「新のみ」のチェックを見ている所を直す
- `tools/mag_stage_test.js`: 「魔防のほうが効くか」の測定を**旧バトルシステムで**やっている（`docs/やり残し.md` のバトルシステム刷新の章）。旧がなくなるので、**1発ぶんのダメージを直接計算する形に書き直す**（同じ章の「宿題」）
- 旧の値を `STATE.battleV2 = false` で読んでいるテストがほかにないか探す（`grep -rn "battleV2" tools/`）
- 既存のテストがすべて通ること

## 3. 終わったら

- `docs/やり残し.md` のバトルシステム刷新の章に「旧は撤去した」と書く
- `docs/design/` などで「新旧を切り替えられる」と書いている所を直す
