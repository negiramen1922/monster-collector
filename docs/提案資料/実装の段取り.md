### この順番にした理由

- **第1段（A＋B）を先に**: 新キャラは新しい奥義SPの表と予算で作ってある。先に入れておかないと、新キャラだけ別のルールで動く。A と B はどちらも「既存キャラのデータの差し替え」で、触る場所（`MONSTER_KITS` の `ult` と `MONSTER_PERKS`）が近い
- **D は E・F の前**: 隠す仕組みがないまま新キャラを入れると、ガチャや図鑑に出てしまう。`MONSTERS` を直接使っている場所が12か所以上あるので、ここが一番手間
- **C はイベントのあとに回す**: セーブデータの移し替えと素材の返却があり、失敗したときの影響が一番大きい。新キャラの数値は「Lv1の値」で書いてあり、今のLv制度（+5%/Lv、上限12）でもそのまま動く。イベント中に新キャラをLv11・12まで上げた人は、第4段でLv10に戻して素材を返す
- **H は index.html と関係ない**ので、いつやってもよい。ただ第3段の測定より前に終わっていると、数値を詰めるときに採点が信用できる

### 間に合わないときに削る順

1. G 立ち絵（「画像準備中」の表示で出せる）
2. F の HELL、E の HELL（EX3までで出せる）
3. F 豊穣の女神を1週遅らせる（桃太郎だけ先に開始）

**A・B・D・E は削らない。**

## 3. 第1段の中身（A＋B）

### A 奥義SP

- 全140体の `ult.sp` を、ロール込みの新しい値にする（`奥義SPの見直し.md` の付録の「SP 今→案」）
- `ultSpCostFor` のロール補正（`BATTLE_V2_ULT_ADJ`）をやめる。データとロールの補正が二重にかからないように、同じ変更で入れる
- 旧バトルシステムに戻したときも、新しい値がそのまま使われる（旧はもともと補正なし）。旧のための別の値は持たない（案）
- 数値を直すキャラ（7章・7-2章・7-3章）の `pow` などと `desc` を直す。**ファラオは全体回復（最大HPの20%）を足す**ので、`run` の中に1行足す
- テスト: `tools/battle_v2_test.js`（「タンクの必要SPは-30」「シューターの必要SPは-20」を見ているので書き換える）、`tools/alpha01_kit_test.js` など、奥義の数値を見ているテスト
- 入れたあと、`sp_probe.js` でロールごとの奥義の回数を測る（サポーターの-20でどれだけ増えたか）

### B 既存の星刻

- `MONSTER_PERKS` の★5の12体・★4の4体を、資料の表のとおりに差し替える
- グリーンマンの属性を草に。タロースのスキル1に挑発1ターン＋ヘイト45
- テスト: `tools/perk_test.js` に足す
