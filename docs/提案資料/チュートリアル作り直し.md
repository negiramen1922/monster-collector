## 2. 暗転のやり方 — 穴あきマスク方式

`z-index` で対象を持ち上げる方式は**使わない**。モーダルの中など別の重なり文脈に入った要素では持ち上がらないため。

対象の `getBoundingClientRect()` を取り、その**上・左・右・下に4枚の暗い板を敷く**。

- 対象の上には何も乗らないので、**穴の中のタップは本物のボタンにそのまま届く**（重なり文脈に関係なく動く）
- 穴の外のタップは板が飲む。押したら穴のリングを揺らして「ここを押して」と示す
- 穴のまわりに光るリングを置いて、ボタンだけ浮いて見せる
- 板は `scroll` / `resize` / 再描画のたびに引き直す

既存の `.guide-spot` は `z-index:1` と内側の光るリングだけで**暗転がない**ので、ここから作る。

## 3. ステップの形

```js
{ title, body, spot: '<セレクタ>', await: 'tap', then: () => {...} }
```

| | 挙動 |
|---|---|
| `spot` + `await:'tap'` | 暗転して穴を開ける。**「次へ」を出さない**。そのボタンを押したら次へ |
| `spot` のみ | 暗転して穴を開けるが「次へ」で進む（場所を見せるだけ） |
| `spot` なし | いまどおりの帯だけ |

## 4. チュートリアルにチュートリアルが被るバグ対策

### 原因

```js
function openGuideToast(mascotKey, steps, opts){
  if(guideToastState && opts.key && guideToastState.key === opts.key) return;  // 同じkeyしか止めない
  guideToastState = { ... };   // ← 違うkeyなら無言で上書きされる
```

**同じ key しか弾いていない。** 別の key が来ると `guideToastState` が丸ごと差し替わり、チュートリアルが途中で死ぬ。

### 割り込みうる発火点（全部）

| 行 | ガイド | 危険度 |
|---|---|---|
| 14106 | `monsterDetail`（ハノコ・モンスター詳細を開くと発火） | **tu4で育成→編成に行かせるので確実に踏む** |
| 11375 | `relics`（遺物図鑑） | 踏みうる |
| 22090 | `welcome`（ケットシー） | 初回起動で先に出るが、順序が崩れると被る |
| 22094 | `openNewNewsOnEntry()`（お知らせを自動で開く） | 帯の上にモーダルが乗る |
| 22127 | `replayGuide()` → `clearGuideToast()` | 見直しボタンでチュートリアルを消せる |
| 19746 | `clearGuideToast()` | モーダルを閉じたときに消える |
| 20476 | `tutorialDone` | tu5クリア時。正常 |

### 対策

1. **所有権のロックを1つ持つ。** `tutorialRunning` が立っているあいだ、`openGuideToast` は**チュートリアル自身の key 以外を全部捨てる**（溜めずに捨てる。見直し一覧で後から見られるので）。
2. 同じガードを `replayGuide` と `clearGuideToast` にも入れる。チュートリアル自身の片付けだけ `force` で通す。
3. チュートリアル中は `openNewNewsOnEntry()` と `overlayView` の変更も止める。
4. **マスクの破棄を1つの関数に持たせる。** いまは `clearGuideHighlight` がクラスを外すだけ。片付け漏れで画面が暗いまま残るのが一番怖いので、マスクも必ずここで消す。

### 閉じ込め対策（穴のないマスクは詰む）

- **スキップは常に帯に出す。** どんな状態でも出口がある
- **対象のセレクタが見つからないときはマスクを描かない。** 帯＋「次へ」に落とす。穴のない真っ暗を絶対に作らない
- 10秒待っても対象が現れなければ「うまく押せないときはここ」を足して進ませる
- **ステップ番号は保存しない。** 進行は `clearedStages` と `STATE.tutorialSkipped` だけから決める。リロードしても壊れた途中から再開せず、必ずステージの頭に戻る

**手順の順番が設計そのもの。** 6（鶴翼にする）を7・8（配置）より前に置くことが肝。
`reflowSlots` が行ごとに詰め直すので、f2→f3 でサポートが後衛へ下がり前衛の席が1つ空く。
そこへアタッカーが入り、シューターは後衛に入るので**適正外が1つも出ない**。

10〜12 でわざと一枚盾（前衛1）を踏ませて⚠を見せ、鶴翼に戻して終わる。
`reflowSlots` は f3→f1→f3 で元の並びに戻るので、戻した時点で必ず適正外ゼロ。

※ **ここで `monsterDetail` のハノコが割り込む。** 上のロックで止める。

### 入門の敵に入れないもの

## 6. スキップ

帯に「スキップ」を常設し、押したら確認を出す。

> **チュートリアルをスキップしますか？**
> あとで **設定 → チュートリアルを再開** から、いつでもやり直せます。
> 　［スキップする］　［つづける］

**スキップは「手取り足取りの案内だけ」を止める。** 5本のステージはそのまま残り、普通に遊んで3,700石も全部もらえる。入門はスタミナ0で5本ともすぐ終わるので、まとめて飛ばす必要がない。何も失わないし、再開も案内を戻すだけで済む。

`STATE.tutorialSkipped = true` を立てるだけ。`clearedStages` は触らない。

### 経済の実装との衝突

`firstClear` を作っている行が、経済見直しで変える行と**同じ1行**。

```js
// 旧: firstClear: t.key === 'tu' ? [100, 150, 3200][i]       : isBoss ? 300 : 50 + i * 5,
// 新: firstClear: t.key === 'tu' ? [100,150,200,250,3000][i] : isBoss ? 100 : 30,
//                                  ↑ チュートリアル作業         ↑ 経済作業
```

互いに別の側しか触らないので、**マージ時にこの1行だけ手で合わせれば済む**。
