# 蘇生の点数の測定

Oct 6, 2026 · @ねぎらーめん

採点式（`tools/balance/power_lib.js`）には蘇生の点がない。肩代わりのとき（`redirect_probe.js`）と同じように、ハーネスで測って点を決める。index.html は触っていない。測定は `tools/balance/revive_probe.js`。

## 1. 測り方

- パーティ: ウンディーネ・ミノタウロス・ケルベロス・ベヒモス・サラマンダー（★5・スキルLv10）
- ウンディーネの奥義だけを差し替えて、勝率と、戦闘が終わったときに倒れている数を比べる
- 「回復量100〜400%」（採点式で25点×n）を物差しにして、蘇生が回復何%ぶんかを読む
- ステージ: q6_10h（Lv200）と q7_04h（Lv280）。どちらも**全滅で負ける**ステージ。時間切れで負けるステージ（q6_05h など）では、回復も蘇生も差が出なかった
- 各150戦。**同じ奥義を2回測って勝率が31%と42%に分かれたことがあり、ぶれは±5〜10%ある**

| 蘇生だけ HP60% | — | 26〜29% | 2〜3% |

## 3. 分かったこと

- **蘇生だけの奥義は弱い**: 回復量100%（25点）くらい。きついステージ（q7_04h）ではほぼ効かない。蘇生してもHPが少なく、すぐまた倒れる。だれも倒れていないと空振りになる（倒れるまで待っても、あまり変わらなかった）
- **回復と一緒の蘇生は強い**: 回復量200%に蘇生HP30%を足すと、回復量350〜400%くらいになる。**蘇生1体で40〜50点**
- **蘇生のHPの量は、あまり効かない**: HP30%→60%で +5〜10点くらい
- **「最大HPの○%回復」は、採点式で約10分の1に数えられている**（不具合）。味方全体の最大HP15%回復は、回復量150〜200%（40〜50点）くらいなのに、採点式は3.75点と数える。正しくは「最大HPの1%＝1点（対象の係数をかける。味方全体なら2.5点）」くらい。Lv200〜280・★5で測った値で、Lvや★で変わるかは測っていない

## 4. 採点のルール（2026-10-06 決定）

| 効果 | 点（案） |
| --- | --- |
| 蘇生1体（回復と一緒の奥義） | 40点。蘇生のHPが30%から10%増えるごとに +3点 |
| 蘇生1体（蘇生が中心の奥義） | 20点 |
| 1戦闘に1度だけの蘇生・復活 | 上の半分 |
| 最大HPの○%回復 | ○点 × 対象の係数（味方全体 2.5、自分 1） |

採点式（`power_lib.js`）の直しは、防御の読み違いと一緒に別の作業でやる。

**ファラオ**: 蘇生が中心の奥義で、測定では強くない。重さ5（戦闘でのSP 100→120）にすると見合わない。案は2つ。
- 案A（不採用）: 重さを3にする（戦闘でのSP 100→80）。予算55に対して71%。前に決めた「蘇生のHP40→60%」はやめ、40%のまま
- **案B（決定）**: 重さ5のまま、**味方全体の回復（最大HPの20%）を足す**（39＋50＝89点、103%）。前に決めた「蘇生のHP40→60%」はやめる
