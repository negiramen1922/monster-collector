## 読み方（全キャラ共通）

- **スキル・奥義の数値は「Lv1→Lv10」**（上限10）。威力・回復量・効果量はLv10で1.5倍
- **ターン数**: 味方への付与はLv5とLv10で+1ずつ、敵への付与はLv10で+1（上限5ターン）
- **Lvで変わらないもの**: 通常攻撃・挑発・回数・CT・SP・確率
- **パッシブの数値は「Lv1→Lv5」**（上限5、Lv5で1.5倍）
- **星刻特性**: ★6 スキル1 → ★7 パッシブ → ★8 スキル2 → ★9 奥義 → ★10 そのキャラのコンセプトの大きな強化。星刻では、Lvで伸びる数値（威力・効果量）は上げない
- **物理防御・魔法防御・SPDの上昇・低下はポイント**。防御1ポイントで受けるダメージが1%減る。加速・鈍化はSPDの足し算・引き算
- **命中低下**: その敵の攻撃が外れる確率が上がる（狙われた側の回避率に足される）
- **回復量**は「攻撃力（STR）×回復量%」
- **自分のパッシブで復活したときは「倒れた」に数えない**（★3クリアの「味方が1体も倒れない」に触れない）。ほかの味方による蘇生は「倒れた」に数える
- **奥義の必要SP**は、★では変えず、奥義の重さとロールで決める（ロールの補正込みの値。戦闘でさらに引くことはない）

### モモタロウ（★5・草・アタッカー・ヒューム・物理）

ステータス案（仮）: HP285・STR66・物理防御9・魔法防御8・SPD44（HP寄り）

**コンセプト（想定している立ち回り）**: 元ネタのとおり、動物たち（ビースト）にきびだんごを配って強くするキャラ。本人も侍なので、刀で戦える青年。HP寄りのステータスで前に立ちつつ、お供を強くして一緒に鬼を斬る。

| --- | --- | --- |
| 通常攻撃 | 一太刀 | 敵単体に威力100%の物理攻撃を行う |
| スキル1 (CT3) | きびだんご | きびだんごが付いていない味方のうち、自分以外で攻撃力が一番高い味方に「きびだんご」を3→5ターン付与する。全員に付いているときは使わず、スキル2か通常攻撃を行う（CTは使わない） |
| スキル2 (CT4) | 鬼斬り刀 | 敵単体に威力280→420%の物理攻撃を行う。デーモンへの与ダメージ+30% |
| パッシブ | 日本一の旗印 | 味方のビースト1体につき、与ダメージ+6→9%（最大3体） |
| 奥義 (SP100) | 鬼ヶ島攻め | 敵全体に威力160→240%の物理攻撃を行う。きびだんごが付いていない味方のビースト全員に「きびだんご」を2→4ターン付与する |

| 星刻 | 特性 |
| --- | --- |
| ★6 スキル1 | きびだんご: 付与した味方のスキルの残りCTを1短くする |
| ★7 パッシブ | 日本一の旗印: 数えるビーストが最大3体 → 4体 |

**きびだんご**: 攻撃力上昇（+20→30%）。ビーストなら、さらに攻撃力上昇（+16→24%）と加速（SPD+10→15）、付与時にSP+15。すでに付いている味方には付与しない（付け直し・延長はしない）。数値はモモタロウのスキルLvで伸びる。
