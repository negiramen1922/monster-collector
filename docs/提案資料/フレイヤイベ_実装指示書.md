# フレイヤイベ（豊穣の女神）実装指示書

Oct 6, 2026 · @ねぎらーめん

`docs/提案資料/次回イベント案_フレイヤ.md` の内容を、index.html に入れて**試験場で遊べる**ようにするための指示書。中身（数値・文言）の正は企画の資料のほう。食い違ったら企画の資料に合わせ、この指示書を直すこと。

書き方は `モモタロウイベ_実装指示書.md` と同じ。**共通の仕組み（`finalWave`・`ev.relic`・HELL・`releaseAt`）は、モモタロウイベで作ったものを使う**。モモタロウイベを先に入れ、そのあとこちらを入れる。

開催予定: 10/13ごろ〜10/26ごろ（「桃太郎」と2本同時）。

**前提**: `第1段_実装指示書.md`（奥義SP・スキルLv/パッシブLv・敵のスキルLv上限10）、`公開日まで隠す仕組み_実装指示書.md`、`モモタロウイベ_実装指示書.md` が入ったあとに行う。

- 奥義の必要SPは「重さ×ロール」の表の値をそのまま書く（戦闘中のロール補正はない）
- スキル・奥義の数値は Lv1 の値。Lv10で1.5倍、パッシブは Lv5で1.5倍
- 新キャラ8体と新遺物2つには `releaseAt`（イベントの `startAt` と同じ）を書く

## 1. 進め方

1. **試験場**（`index.html?lab=freyja`）で遊べるところまで作る。本番のセーブとクラウドに書かない
2. ユーザーが試験場で遊んで数値を詰める
3. 決まったら本番の `EVENTS` に入れる（開始日時・お知らせ・バナー）

試験場でできてほしいこと:
- 新キャラ8体を、Lv・★（★2〜★10）・スキルLv（1〜10）・パッシブLv（1〜5）を選んで手持ちに入れられる
- クエスト1〜10層、EX1〜EX3、HELLを、日付に関係なく選んで戦える
- 既存のキャラも編成に入れられる

### 新しく作る仕組み

| 仕組み | 使うキャラ | メモ |
| --- | --- | --- |

### 採点式についての注意

`tools/balance/power_lib.js` は、防御の上昇・低下（ポイント）と、最大HPの○%の回復を、正しく数えない。この2つが入ったスキルの採点は信用しないこと（`蘇生の点数の測定.md`）。

## 4. 星刻特性（`MONSTER_PERKS`）

8体とも、企画の資料の表のとおり★6〜★10を入れる。**★6でスキル1、★7でパッシブ、★8でスキル2、★9で奥義、★10でコンセプト**の決まりで作ってある。テストは `tools/perk_test.js` に足す。

## 5. 遺物（`RELICS`）

| ID（仮） | 名前 | ★ | 基本 | 効果 |
| --- | --- | --- | --- | --- |
| rel_hawk_cloak | 鷹の羽衣 | 5 | バランス型B `{ hp:85.4, atk:19.8 }` | `hp 0.15 無条件` / `atk 0.15 role:support` / `spGain 0.165 mon:m177` |
| rel_golden_ear | 黄金の麦穂 | 4 | バランス型G `{ hp:67.6, atk:14.5 }` | `atk 0.125 無条件` / `spGain 0.125 element:earth` / `ultDmg 0.125 element:earth` |

- 数値は企画の資料の「初期→最大」の初期の値。**中身はまだ「決めてほしいこと」に入っている。ユーザーに確認する**
- 効果の種類の名前（`spGain`・`ultDmg` など）は、既存の遺物の書き方に合わせる。同じものがなければ足す
- 専用遺物は `exclusiveRelicForMon` で引けるようにする
- 黄金の麦穂はガチャに出さない。**イベントショップで本体（200メダル×1）と重複（200メダル×4）を売る**（`ev.relic`）
- 2つとも `releaseAt` を書く。アイコンは `RELIC_ICON` に SVG を足す

```js
{
  key: 'ev_freyja',

  pickup: 'm177',
  featured: ['m177', 'm178', 'm179'],

  terrain: 'field',
  element: 'earth',
  relic: 'rel_golden_ear',
  waveSizes: [3, 3, 4, 4, 5],
  escortPools: [
    { from: 1, list: [/* エインヘリャル・コボルト・ジャッカロープ・マッドモール・ピクシー・ウィスプ */] },
    { from: 5, list: [/* エインヘリャル・ヒルデ・スコグル・ゲンドゥル・ヒルジャイアント・ドリュアス・アルヴィス */] },
    { from: 8, list: [/* ヒルデ・ブリュンヒルド・スコグル・ゲンドゥル・エインヘリャル・ミノタウロス・ブロック・ユミル */] },
  ],
  finalWave: ['m178', 'm179', 'm181', 'm183'],   // ボス(フレイヤ)の後ろに固定。フレイ・ヒルディスヴィーニ・ヒルデ・スコグル
  tiers: [ /* モモタロウイベと同じ10段 */ ],

```

- **ゴブリンは出さない**
- メダル（`EVENT_MEDAL`）・称号（`EVENT_TITLES`）・色（`EVENT_THEME`）・イベントショップも、前回と同じ形で足す
- 話の筋: 戦死者の半分を館に迎える女神フレイヤが、館に迎える戦士を選ぶため、腕を試してくる

## 7. EX（`EVENT_EX` / `EVENT_EX_RULES`）

### 段

| 段 | lv | boss | mob | sk | 初回クリアの石 |
| --- | --- | --- | --- | --- | --- |
| EX1 | 80 | 6 | 4 | 8 | 100 |
| EX2 | 200 | 8 | 5 | 10 | 200 |
| EX3 | 300 | 10 | 6 | 10 | 400（★3クリアで称号） |
| **HELL** | 300 | 10 | **10** | 10 | 500（★3クリアで称号と、フレイヤの入った派手なアイコンフレーム） |

- sk（敵のスキルLv）は10まで（企画の資料の12は、上限が10になったので10に読み替える）
- EX1 の lv は企画の資料で「70〜85」。モモタロウイベに合わせて80にした（測って直してよい）
- 各段10体まで: フレイヤ / フレイ・ヒルディスヴィーニ / ブロック・ミノタウロス / エインヘリャル・ヒルデ・ブリュンヒルド・スコグル・ゲンドゥル
- 最終ウェーブは「フレイヤ・フレイ・ヒルディスヴィーニ・ヒルデ・スコグル」。前後の配置（`:front` / `:back`）を必ず書く
- **主役以外の★5は入れない**
- HELL は名前「HELL」（画面では「黄金のフォールクヴァング・HELL」）。解放条件は EX3 クリア

### ルール（`EVENT_EX_RULES.ex_freyja`。段ごとに足す形。**数値は仮**）

| 段から | 書き方 | 表示 |
| --- | --- | --- |
| EX1 | `{ who:{ element:'earth' }, side:'ally', stat:{ str:0.25, hp:0.25 } }` | 土属性の味方 攻撃力・HP+25% |
| EX1 | `{ who:{ element:'light' }, side:'ally', stat:{ str:0.25, hp:0.25 } }` | 光属性の味方 攻撃力・HP+25% |
| EX1 | `{ who:{ species:'celestia' }, side:'ally', stat:{ str:0.25 } }` | セレスティアの味方 攻撃力+25% |
| EX1 | `{ who:{ species:'elf' }, side:'ally', stat:{ str:0.25 } }` | エルフの味方 攻撃力+25% |
| EX2 | `{ side:'enemy', stat:{ pdef:50 } }` | 敵 物理防御+50 |
| EX3 | `{ side:'ally', dmgDealt:0.3, whenTarget:'strDown' }` | 攻撃力低下状態の敵への与ダメージ+30% |
| EX3 | `{ side:'ally', dmgTaken:0.3, when:'notShielded' }` | 味方: シールドがないとき、受けるダメージ+30% |
| HELL | `{ who:{ ref:'m177' }, side:'enemy', stat:{ str:0.5, hp:0.5 } }` と フレイ（m178）も同じ | 敵のフレイヤ・フレイ 攻撃力・HP+50% |

- **新しい条件が2つ**: `whenTarget:'strDown'`（攻撃力低下状態の相手）と `when:'notShielded'`（自分にシールドがないとき）。今あるのは `shielded` など
- `dmgTaken` の書き方が今の `EVENT_EX_RULES` にないときは、既存の「受けるダメージ」の書き方に合わせる

## 8. 測る

試験場ができたら、`tools/` のハーネスで次を測って企画の資料に書く。

- クエスト10層: 3パーティ（高レア / 基本B / 気絶）で各層40戦
- EX1: Lv70・★4・スキルLv3・遺物ルーンなし（総BP約11,000）で60〜90%
- EX3: Lv250・★5・スキルLv10・遺物★5Lv80＋ルーンⅧ金×2（総BP約74,000）で30〜70%、1戦12ラウンド以下
- HELL: Lv300・★10・スキルLv10・パッシブLv5・遺物とルーンを積んだ編成で10〜40%
- **敵のフレイヤが回復し続けて戦闘が長引かないか**（ラウンド数）。長引くなら、敵のフレイヤだけ回復量を下げるルールを足す（ユーザーに相談）
- 新キャラ: 1体だけのときと、フレイヤと組んだときのダメージ・耐久
