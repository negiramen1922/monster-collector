# お知らせバナー依頼：「紅蓮の九尾」「黄金の巨神」EX開催

既存の `ann_ev_fenrir` / `ann_ev_abaddon` と並べて置くものです。**仕様はその2枚から採寸しました。**

## 既存バナーの仕様（実測）

```
960 x 540 ピクセル(16:9)、WebP、透過なし。1枚 65〜71KB。
左半分(0〜430px)が文字、右半分(430〜960px)がモンスター。
背景は黒に近い地色＋属性色の放射状の光＋その中心に大きな円(日輪/月)。
モンスターはゲームのドット絵をそのまま拡大し、名札を付ける。
```

---

## ⚠️ そのまま画像生成に投げると、たぶん失敗します

理由が2つあります。

1. **日本語の文字が崩れます。** 既存2枚は文字が完璧なので、生成ではなく組版されたものです。画像生成に「紅蓮の九尾」と書かせると、ほぼ確実に別の字になります。
2. **モンスターが別物になります。** 既存バナーのフェンリル・ハティ・スコルは**ゲームのスプライトそのもの**です。生成すると絵柄が変わり、ゲーム内のキャラと一致しません。

**なので、下の「背景だけ生成 → 文字とキャラは合成」を勧めます。** 全部生成したい場合のプロンプトも最後に置いてあります。

---
