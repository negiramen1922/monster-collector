# バベル 均衡の塔を60階に（要件）

Oct 15, 2026 · @ねぎらーめん

均衡の塔を作り直して階を増やす。**全体は100階で考え、今回は1〜60階を作る**（61〜100は後から足す）。秩序の塔・混沌の塔は後で同じ形にする。

## 1. 決まったこと（2026-10-15 ユーザー決定）

- 均衡の塔は**100階まで**の計画。**今回は60階まで実装**し、その後に追加する
- **今の1〜10階も作り直す**（敵の顔ぶれ・ステージ効果とも）
- 階のリズム
  - ○1〜○4・○6〜○9階: **ふつうの戦い**（敵の種族と属性を階ごとに寄せる。有利な属性で組めば勝てる）
  - **5の倍数の階はすべてボス戦で、ステージ効果あり**
- **55階のボスは死神**
- 敵の顔ぶれのかぶりは気にしない（168体しかいないので、階が増えればかぶる）
- 報酬は**星結晶を少しずつ**
- 秩序の塔・混沌の塔は**あとから**
- 出す時期は**要件がまとまってから**決める（今は `?babel=1` の開発者だけ）
- **お助けモンスター（フレンドからの貸し出し）は使えない**（2026-10-19 ユーザー決定。今の作りもそうなっている: 編成に入っていると「バベルではお助けモンスターを使えません」と出て始められない）

| 1〜10 | 初心者〜中級 |

| 71〜100 | 超上級（★10・スキルLv10・ルーンⅩ・★5遺物カンスト） |
| 101〜（後で） | 超上級＋編成をよく考えないと勝てない |

- 合格の基準は今と同じ: **勝てる想定で勝率80%以上**、**1段上の育ちでも勝てない想定は20%以下**（ボス戦の階は「勝てない想定」を、ステージ効果に合わない編成にする）
- 敵の強さ（★・スキルLv・HP/STRの底上げ）は `tools/babel_tune.js` で階ごとに合わせる

## 4. 報酬（案）

| 階 | 星結晶 |
| --- | --- |
| ふつうの階 | 20 |
| ボスの階（5の倍数） | 50 ＋ 素材（ワザ素材BOX・EXPポットなど） |

- 1〜60階で 48×20 + 12×50 = **1,560**（今の均衡の塔は10階で600）
- 1〜100階で **2,600**
- 初回クリアのみ・リセットなし（今と同じ）

### 6-5. 試験場の見え方

- 階の一覧は1〜60を10階ずつに区切り、ボスの階に「ボス」の印。
- 階の表示で、各WAVEの敵を戦闘と同じ **後衛／前衛** の並びで出し、1体ずつ 属性・ロール・★・Lv・スキルLv・パッシブLv・ボスの印 を出す。
- 勝てる想定・勝てない想定の編成も同じ並びで出す（育ち・ルーン・遺物の★つき）。「編成に入れる」で下の編成に入る。
- キャラをタップすると、図鑑の詳細と同じ形で **ワザ（通常・スキル1・スキル2・パッシブ・奥義）と星刻** が出る。ワザはそのスキルLvでの威力、星刻はその★までに開いたものが光る。この階で戦うときの能力値（ステージ効果・塔の底上げ込み）も出す。

### 6-6. 残っていること

- 勝率は30回ずつなので、80%・20%に近い階（4・7など）は、測り直すと数%ぶれる。
- 勝てる想定に★5（雷電・リヴァイアサン・グリーンマンなど）が入っている階がある。持っていないプレイヤー向けの別の組み方は、まだ測っていない。
- 秩序の塔・混沌の塔を同じ形（60階）にするのは、あとから。
