# バベル 均衡の塔を60階に（要件）

Oct 15, 2026 · @ねぎらーめん

均衡の塔を作り直して階を増やす。**全体は100階で考え、今回は1〜60階を作る**（61〜100は後から足す）。秩序の塔・混沌の塔は後で同じ形にする。

## 1. 決まったこと（2026-10-15 ユーザー決定）

- 均衡の塔は**100階まで**の計画。**今回は60階まで実装**し、その後に追加する
- **今の1〜10階も作り直す**（敵の顔ぶれ・ステージ効果とも）
- 階のリズム
  - ○1〜○4・○6〜○9階: **ふつうの戦い**（敵の種族と属性を階ごとに寄せる。有利な属性で組めば勝てる）
  - **5の倍数の階はすべてボス戦で、ステージ効果あり**
- **55階のボスは死神**
- 敵の顔ぶれのかぶりは気にしない（168体しかいないので、階が増えればかぶる）
- 報酬は**星結晶を少しずつ**
- 秩序の塔・混沌の塔は**あとから**
- 出す時期は**要件がまとまってから**決める（今は `?babel=1` の開発者だけ）

## 2. 育ちの上がり方（案）

| 階 | 勝てる想定の育ち |
| --- | --- |
| 1〜10 | 初心者〜中級 |
| 11〜30 | 中級（★＋2・スキルLv6・ルーンⅢ・★3遺物Lv50） |
| 31〜50 | 上級（★＋5・スキルLv10・ルーンⅦ・★4遺物Lv150・2凸） |
| 51〜70 | 上級＋（★9・スキルLv10・ルーンⅨ・★5遺物）※新しく足す段 |
| 71〜100 | 超上級（★10・スキルLv10・ルーンⅩ・★5遺物カンスト） |
| 101〜（後で） | 超上級＋編成をよく考えないと勝てない |

- 合格の基準は今と同じ: **勝てる想定で勝率80%以上**、**1段上の育ちでも勝てない想定は20%以下**（ボス戦の階は「勝てない想定」を、ステージ効果に合わない編成にする）
- 敵の強さ（★・スキルLv・HP/STRの底上げ）は `tools/babel_tune.js` で階ごとに合わせる

## 3. ボス（5の倍数の階）（案）

| 階 | ボス | 属性 |
| --- | --- | --- |
| 5 | オークジェネラル（★4） | 無 |
| 10 | ミノタウロス（★4） | 土 |
| 15 | クラーケン（★4） | 水 |
| 20 | ケルベロス（★4） | 炎 |
| 25 | グリフォン（★4） | 風 |
| 30 | ミスリルゴーレム（★4） | 雷 |
| 35 | メデューサ（★4） | 闇 |
| 40 | タロース（★5） | 土 |
| 45 | リヴァイアサン（★5） | 水 |
| 50 | バハムート（★5） | 炎 |
| **55** | **死神（★5）**（決定） | 闇 |
| 60 | ホーリードラゴン（★5） | 光 |

- 61〜100のボスには、残りの★5（タイタン・フェンリル・九尾の狐・雷電・グリーンマン・アバドン・シースライム・モモタロウ・フレイヤ）とイベントの新しい★5を回す
- ボスの階のステージ効果は、ボスの性格に合わせて1つずつ作る（例: 死神=倒れた味方の数で敵が強くなる、など。中身は階ごとの表で出す）

## 4. 報酬（案）

| 階 | 星結晶 |
| --- | --- |
| ふつうの階 | 20 |
| ボスの階（5の倍数） | 50 ＋ 素材（ワザ素材BOX・EXPポットなど） |

- 1〜60階で 48×20 + 12×50 = **1,560**（今の均衡の塔は10階で600）
- 1〜100階で **2,600**
- 初回クリアのみ・リセットなし（今と同じ）

## 5. 次にやること

1. この要件の確認（ボスの並び・報酬の数）
2. 1〜60階の階ごとの表（名前・敵の顔ぶれ・ボス戦のステージ効果・勝てる/勝てない想定の編成）を作る
3. 試験場（`?lab=babel`）で測って合わせる
4. 出す時期とお知らせを決める
