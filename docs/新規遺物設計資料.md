## 1. 既存の遺物システムのルール(前提)

- 効果本数は★で差別化: ★1=1本(誰でも)・★2/★3=2本(誰でも+条件)・★4/★5=3本
  (誰でも+条件1+条件2、条件が狭いほど強い)。
- 効果の%は「skillLv1(Lv1)の生値」で定義され、`relicSkillMult(skillLv)`で
  `1 + (skillLv-1)/9` 倍される。skillLv10(カンスト)で**ちょうど2倍**になる
  (=Lv1の値を単純に2倍すればカンスト値)。
- 同じstatを狙った複数effectsは自動的に合算される(コード側で明示的なstackフラグ不要)。
  合算を意図する場合は、他の項目の「条件側だけの単独値」と同じ最終値になるよう、
  誰でも側の値を引いた分だけ条件側を小さくする(例: 他の属性は誰でも9%+条件17%=26%
  ではなく、条件側だけで17%という「単独値」を揃えたいので、合算する属性は
  誰でも9%+条件8%=17%にする。★4のrel_verdant_breath[パーンの葦笛]が実例)。
- 到達cap(全条件一致・カンスト時):
  - ★3: 誰でも8%→16% + 条件16%→32%
  - ★4: 誰でも9%→18% + 条件17%→34% + ロール14%→28%
  - ★5(汎用2種): 誰でも7%→14% + 条件9%→18%(合算例あり) + 条件16%→32%
  - ★5(専用6+5種、そのキャラ本人だけの3本目がある分だけ強い): 誰でも5%→10% +
    種族/ロール4%→8% + 本人専用18%→36%
- ★4遺物の基礎ステータス(base)プリセット: E=HP34.4/STR21.6(atk型)、F=HP100.9/STR7.4
  (hp型)、G=HP67.6/STR14.5(バランス型、風のみ+SPD6.5)。
- ★5遺物の基礎ステータスプリセット: A=HP43.4/STR29.6(atk型)、B=HP85.4/STR19.8
  (バランス型)、C=HP127.5/STR10.1(hp型)、D=HP85.4/STR19.8/SPD8.4(SPDレア型)。
- ★3遺物の基礎ステータスプリセット: H=HP67.2/STR4.9(tank型)、I=HP22.4/STR14.7
  (atk型)、J=HP44.8/STR9.8(バランス型)。
