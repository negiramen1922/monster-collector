## ★5 (13種)

### 業炎の魔剣 (rl01)
- 対象: バハムート専用(新規★5/炎・attacker・ドラコニア)
- 基礎ステータス: HP+43.4 / STR+29.6 (プリセットA)
- 効果[誰でも] STR +15% → +30%
- 効果[role: attacker] STR +15% → +30%
- 効果[本人のみ] スキル攻撃力 +16% → +33%
- 由来: 立ち絵の鉤爪。火口の底で、岩を掴んだまま朽ちた炎竜から剥がれ落ちた爪。今も熱を失わない。
- メモ: コメント反映: 会心率をやめてSTR2段に。会心倍率1.5倍のままでは会心が伸びないという指摘に沿う。

### ヨルムンガンドの鱗 (rl02)
