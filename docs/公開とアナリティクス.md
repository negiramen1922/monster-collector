# 公開手順とアナリティクス

## 1. 公開(GitHub Pages)

1. GitHub → Settings → Pages → Source: **Deploy from a branch** / Branch: `main` / `/ (root)`
2. 数十秒で `https://negiramen1922.github.io/monster-collector/` が開きます
3. **Firebase → Authentication → Settings → 承認済みドメイン**に `negiramen1922.github.io` を追加
   （パスは不要。これが無いとGoogleログインだけが失敗します）
4. **Firestore → ルール**に `firestore.rules` の内容を反映

公開先を変えたら、`index.html` の `og:url` と `og:image`(絶対URLが必要)も直してください。

### 公開ページの体裁

| 項目 | 内容 |
|---|---|
| favicon | `assets/favicon.png`(64px) / `assets/icon-180.png`(ホーム画面用) |
| OGP | `assets/ogp.png`(1200×630)。SNSに貼るとタイトル・説明・モンスターが出ます |
| 読み込み中 | JSが動く前に、タイトルと「読み込み中…」を出します(白い画面を見せない) |
| テーマ色 | `#0f0c1a`(スマホのアドレスバーの色) |

これらは `CHROMIUM_PATH=... python3 tools/make_branding.py` で作り直せます（立ち絵とアイコンから組み立てます）。

## 2. アナリティクス(Firebase Analytics / GA4)

`FIREBASE_CONFIG.measurementId` を使って、ログイン後に読み込みます。**失敗しても遊びには影響しません**
(広告ブロッカー・非対応ブラウザ・オフラインでは、単に送られません)。

### 送っているイベント

| イベント | いつ | パラメータ |
|---|---|---|
| `login` / `sign_up` | ログイン / メールで新規登録 | `method`(google/email/guest) |
| `game_start` | セーブがまだ無い人が始めたとき | `method` |
| `account_link` | ゲストからの引き継ぎ | `method` |
| `screen_view` | 画面切り替え | `screen_name` |
| `tutorial_begin` / `tutorial_complete` | チュートリアル1開始 / 3クリア | - |
| `stage_start` | 出撃 | `stage_id` `tier` `type` |
| `stage_clear` | クリア | `stage_id` `tier` `type` `rank` `rounds` `first` |
| `stage_fail` | 敗北・時間切れ | `stage_id` `tier` `type` `wave` `rounds` `reason`(wipe/timeout) |
| `gacha_pull` | ガチャ | `count` `best`(最高レアリティ) |
| `monster_promote` | ★昇格 | `monster` `star` |
| `sweep` | 周回 | `stage_id` `type` `times` |

ユーザーには `uid` を紐づけ、ユーザープロパティ `provider` を付けます。**メールアドレスや名前は送りません。**

### GA4側で最初にやること

パラメータは**カスタムディメンションに登録しないとレポートに出ません**。
GA4 → 管理 → カスタム定義 → カスタムディメンションを作成 で、イベントスコープで登録してください。

優先して登録するもの: `stage_id` / `tier` / `reason` / `rank` / `method` / `screen_name` / `best`

### 公開直後に見ると分かること

- **どこで脱落するか**: `tutorial_begin` → `tutorial_complete` → `stage_clear`(q1_01…) の推移
- **詰まっているステージ**: `stage_fail` を `stage_id` で分解。`reason=timeout` が多いなら火力不足
- **ガチャを回しているか**: `gacha_pull` の人数と回数
- **ログイン方法の内訳**: `login` の `method`
- 継続率・セッション時間・端末はGA4が自動で取ります

### イベントを足すとき

`logEvent('名前', { パラメータ })` を呼ぶだけです(ミッション集計の `track()` とは別物なので注意)。
`tools/mock_auth.js` が記録するので、`auth_test.py` から中身を検証できます。
