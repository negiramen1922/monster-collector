## 1. いつもの進め方

- ゲーム本体は `index.html`（1ファイル）。
- 変更ごとの手順:
  1. 実装する。
  2. テストする。node のテスト（`tools/*_test.js`）と、Playwright の画面テスト（`tools/*_ui_test.py`）を使う。
  3. `GAME_VERSION` を1つ上げ、`UPDATE_LOG` に項目を足す。
  4. コミットする。コミットメッセージの最後に次の2行を付ける。
     ```
     Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
     Claude-Session: https://claude.ai/code/session_01XV2cx7dmaMmSiVFCb784rH
     ```
     （新しいセッションでは、そのセッションの URL に置き換える）
  5. `claude/fervent-keller-0768me` に push してから、`git push origin HEAD:main` で main に出す。
  6. ユーザーには日本語で報告する。スクリーンショットや音声ファイルがあれば一緒に渡す。
- **ユーザーが「mainに出して」と言うまで main に出さないもの**があります。大きな調整やイベントなどです。ユーザーが確認してから出します。
- PR は頼まれたときだけ作る。コミットにモデル名は書かない。
- ユーザー向けの告知は2か所あります。
  - `UPDATE_LOG`: アップデート内容のタブ
  - `NOTICES`: ニュースのタブ。未読のニュースがあると、ゲームに入ったときに自動で開く。
    - `art: ['m68', 'm139']` を付けると、本文の上にキャラの立ち絵が並ぶ。

### テストの動かし方

- `cd tools && python3 extract.py` で `tools/game.js` を作る（`index.html` を変えたら毎回）。harness は `game.js` を今いるフォルダから読むので、`tools/` の中で動かす。
- 画面テスト: `CHROMIUM_PATH=/opt/pw-browsers/chromium SHOT_DIR=<保存先> python3 tools/xxx_ui_test.py`

### 付与率と持続時間のルール（α0.1.072）

`今後やりたいこと.json` の `bl_skill_chance` にも書いてあります。

- **付与率**: スキルLvでもパッシブLvでも変わらない（固定）。
  - 効果ごとの目安: 気絶・魅了・拘束 20〜30%、石化 15〜25%、混乱 25〜35%、麻痺 30〜40%、**やけど・毒は基本50%**、弱体化 50〜80%、追撃 40〜60%。
  - 全体技は目安の下の端にする。多段技はヒットごとの確率なので、キャラごとに決める。
- **必殺技**: 状態異常・弱体化・追撃はすべて確定。
  - ミノタウロス・ジャッカロープ・キョンシー・キラービーの必殺技に気絶を追加した。
  - キョンシーは `to:'foeTopHp'`（HPが一番高い敵1体）、キラービーは `to:'foeLastHit'`（最後に当たった敵）。
- **持続時間**（`grownTurns` / `statusTurns`）:
  - 味方への数値バフ: スキルLv5 と Lv10 で1ターンずつ伸びる。
  - 敵への弱体化とやけど: Lv10 で1ターン伸びる。
  - 行動封じ・挑発・肩代わり・免疫などは伸びない。
  - どれも上限は5ターン。通常攻撃とパッシブは伸びない。
- **パワー予算**（新しいキャラを作るときの基準。1点 = 単体に威力10%）:
  - CT: CT2 18、CT3 22、CT4 27、CT5 32
  - SP: SP80 45、SP90 50、SP100 55、SP110 62、SP120 70
  - ★の係数: ★1 ×0.85、★2 ×0.9、★3 ×1.0、★4 ×1.1、★5 ×1.2
  - 必殺技は予算の100〜130%を目安にする。
- 残っている作業:
  - 405件すべてのスキルを採点し、予算から外れた技を個別に調整する（例: ボルケイノタートルの噴火弾が予算の173%）。
  - 回復の点の付け方を決める。
  - 凸ボーナス★9の「付与率アップ」段を書き直す。
