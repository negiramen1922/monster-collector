## 3. スキルの付与率と持続時間（α0.1.072 で実装済み）

資料: `docs/提案資料/付与率と持続時間の見直し.md`

- 全キャラの「今と見直し案」の比較表: `docs/提案資料/スキル比較表.html`
  - claude.ai 版: https://claude.ai/artifact/A2SWYSwiSf6K4jRyPKcUyc
  - 「特に注意するキャラ」の絞り込みもある。
- 設計メモ: `bl_skill_chance`

**ルール**

- 付与率はスキルLvでもパッシブLvでも変わらない（固定）。上げられるのは、凸ボーナスと付与率アップの遺物・パッシブだけ。
- スキルの付与率の目安:

  | 効果 | 目安 |
  |---|---|
  | 気絶・魅了・拘束 | 20〜30% |
  | 石化 | 15〜25% |
  | 混乱 | 25〜35% |
  | 麻痺 | 30〜40% |
  | やけど・毒 | 基本50%（ユーザーの指定） |
  | 弱体化 | 50〜80% |
  | 追撃 | 40〜60% |

  - 全体技は目安の下の端にする。
  - 多段技はヒットごとの確率なので、キャラごとに決める（ケルベロス30%、ヒノコ20%のまま）。
- 必殺技の状態異常・弱体化・追撃は、すべて確定。
  - スキルに気絶があるのに、攻撃の必殺技に行動封じがなかった4体には、必殺技に気絶を足した。
  - ミノタウロス・ジャッカロープ（onHit）
  - キョンシー（`to:'foeTopHp'` = HPが一番高い敵1体）
  - キラービー（`to:'foeLastHit'` = 最後に当たった敵）
- 持続時間（`grownTurns` / `statusTurns` / `DUR_FIXED_BUFFS`）:
  - 味方への数値バフ: スキルLv5 と Lv10 で1ターンずつ伸びる。
  - 敵への弱体化とやけど: Lv10 で1ターン伸びる。
  - 行動封じ・挑発・肩代わり・免疫・状態異常無効・石像化・キャラ固有の状態は伸びない。
  - どれも上限は5ターン。通常攻撃とパッシブは伸びない。
  - スキル強化の画面に「持続 2ターン → 3ターン」の行が出る。
- 威力・効果量は今までどおり、1Lv ごとに+5%（Lv12 で1.55倍、割合の効果は80%が上限）。
- **パワー予算**（新キャラを作るときの基準。点の付け方は `tools/balance/power.js`）:
  - 1点 = 単体に威力10%。
  - CT: CT2 18、CT3 22、CT4 27、CT5 32
  - SP: SP80 45、SP90 50、SP100 55、SP110 62、SP120 70
  - ★の係数: ★1 ×0.85、★2 ×0.9、★3 ×1.0、★4 ×1.1、★5 ×1.2
  - 必殺技は予算の100〜130%を目安にする。140%を超えたら威力を下げる。
- 影響の実測: 全メインクエスト（通常・ハード）で勝率はほぼ変わらない（クエストごとの平均で±4pt以内）。気絶パーティだけ、一部のステージで+20〜35pt。

**残っている作業**

- 405件すべてのスキルを採点し、予算から外れた技を個別に調整する。
  - 例: ボルケイノタートル 噴火弾 173%、スルト 灼熱の薙ぎ 142%、ヴェノムスライム 酸の雨 142%、メデューサ ゴルゴンの真視 144%、ドルイド 茨の呪い 58%
- 回復・リジェネ・特殊な動き（`run`）のスキルの点の付け方（案: 回復量10% = 1点）。
- 提案資料の「確認してほしいこと」のうち、係数・予算・必殺技の上限は、ユーザーがはっきりとは承認していない（「このまま実装進めてもいい気がします たぶん」で実装した）。
- `tools/balance/` のスクリプトは、α0.1.072 より前のキットで作った。今のキットで走らせると、「今」の欄が新しい値になる。
