## 0. 置き換えのルール

1. **置き換えるのは、画面に出る文言だけ**です。変数名・関数名・定数名・`STATE` のキー・アイテムのキーは、そのまま残します。
   - 残すものの例: `relic_scrap`、`relic_core_1`、`HATE_BUFF`、`STATE.resonance`、`skillLv`
   - キーを変えると、今のセーブデータが読めなくなります。
2. **マスコットのガイド文・チュートリアル文・ミッション文・解放のお知らせ**も置き換えます。
   - 対象: `GUIDE_CONTENT`、`TUTORIAL_PAGES`、`BEGINNER_MISSIONS`、`unlockDefs()` など
3. **更新履歴(`version: 'α…'` の行)の過去の記事は書き換えません。** 当時の名前のまま残し、今回の変更は新しい記事で知らせます(7章)。
4. コメント(英語)は、必要に応じて直せば十分です。
5. `tools/` のテストには、画面の文言を確かめているものがあります。置き換えたら、テスト側の文字列も合わせて直します(6章)。
6. このあと出てくる行番号は、2026-09-28時点(コミット `23d6ea5`)のものです。検索するときの目安にしてください。

## 5. 名前の変更だけでは済まないもの

### 5-1. 〇〇の共鳴石(かぶった遺物)
- **今の仕組み**: かぶった遺物は、同じ遺物のまま `dupe` として数えています。それを使って覚醒しています(`st.dupe` / `st.dupeUsed` / `dupeSpare` 6944付近)。足りない分は、共鳴石を `RESONANCE_PER_DUPE`(3151)個使って代わりにできます。
- **新しい見せ方**: かぶった遺物は「〇〇の共鳴石」として持ち、これで共鳴します。どの遺物にも使える石は「無形の共鳴石」と呼びます。
  - モンスター側の「ソウル/無形のソウル」と同じ形です。
- **データ**: `dupe` / `dupeUsed` をそのまま「〇〇の共鳴石」の所持数として見せれば、セーブの形は変えずに済みます。
- **見た目**: 次の場所を作り直す必要があります。
  - 遺物ガチャの結果表示(「かぶり」→「〇〇の共鳴石を入手」)
  - 遺物強化画面
  - アイテム欄
  - 遺物図鑑の絞り込み

### 5-2. 下のメニュー「育成」
- `NAV` の `label` を変えます。キーの `'party'` は変えません。
- ようこそガイド(18982)の「探索・編成・ガチャ・拠点」も、今のメニュー(ガチャ/育成/ホーム/探索/拠点)に合わせて直します。
- ミッションのヒントなどに出てくる「パーティ画面で」「パーティ画面の陣形カード」は、「育成 → 編成」の形に揃えます。

### 5-3. 最大レベルと上限解放の使い分け
- **最大レベル**: ★(星刻)で決まる上限です。最大Lv300。
- **上限解放**: Lv30・50・100…(`LEVEL_WALLS` 4841)でゴールドを払って先へ進むことです。
- 詳細画面の「上限 Lv◯」「★を上げるとレベル上限が伸びます」は、最大レベルのほうです。「Lv◯の壁を限界突破」は、上限解放のほうです。

### 5-4. 「クエスト」の範囲
- 探索メニューの見出しと副題は、「クエストと呼ぶのはメインクエストと育成クエストだけ」になっているか確認します。
- 深淵回廊・イベント・PVPを「クエスト」と呼んでいる所がないかも確認します。

## 6. 作業の手順と確認

1. 2〜4章の表のとおりに、画面の文言を置き換えます(`index.html`)。
2. 置き換え漏れを検索で確認します。0件になればよい語と、残っていてよい語は次のとおりです。

   ```bash
   # 更新履歴(version: 'α…)とコメントを除いて、表示文言だけを調べる
   grep -n "昇格\|覚醒\|限界突破\|壁を突破\|必殺技\|スクラップ\|遺物のコア\|アーティファクト\|水晶\|育成ダンジョン\|お助けキャラ\|キャラ一覧\|育成素材\|スキル素材" index.html | grep -v "version: 'α" | grep -v "^\s*[0-9]*:\s*//"
   ```
   - 「覚醒」は、遺物の新しい名前が「共鳴」なので0件になるはずです。
   - 「結晶」は「星結晶」「無形の…」の中に残ってよい語です。「キャラ」も残らないようにします。
3. `tools/` のテストで画面の文言を確かめているものを直します。該当する語を含むファイルは次のとおりです(2026-09-28時点)。
   - **遺物系**: `relic_detail_ui_test.js`、`relic_dupe_filter_test.js`、`relic_spark_test.js`、`relic_test.js`
