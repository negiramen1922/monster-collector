## 立ち絵

リポジトリ直下の `sprite_XXXX.png` はアップロードされたままの原寸画像で、
ファイル名が連番のため中身が分かりませんでした。確認ツールのサムネイルと
画像の指紋(16x16に潰した明暗パターン)で突き合わせて対応を確定しています。

- `tools/match_sprites.py` … 突き合わせて `tools/sprite_map.json` を書く
- `tools/sprite_map.json` … 名前 から ファイル名 から sprite-data の番号
- `tools/add_sprites.py` … PNGを 256x256 のwebp(既存と同じ形)にして index.html に入れる

**30体すべての立ち絵がそろっています。** 後から届いた シームルグ・サキュバス・死神 は
`dreamina-*.png` として置かれていたもので、目視で確認して 163〜165 を振りました。
メデューサは後から届いた `sprite_2784.png`(下半身が蛇の絵)に差し替えました(ユーザー指定)。
以前の `sprite_1949.png`(紫の服の絵)は使っていません。
`match_sprites.py` は `sprite_map.json` に書いてある対応と番号を優先するので、回し直しても変わりません。

リポジトリ直下には、どのキャラにも割り当てていない画像が残っています(α0.1の30体には含まれない):

- `dreamina-2026-09-25-5245` / `-5290` / `-5833` / `-9810` … 鉢巻の雉・桃太郎風の少年・鉢巻の柴犬・スライム

絵が増えたら `match_sprites.py` を回し直してから `gen_design_docs.py` を実行してください(設計資料のmdに立ち絵の有無が出ます)。

## 残りの進め方(おすすめの順)

### 1. MONSTERS に30体を足す

`index.html` の `monster-data`(JSON)に追記します。既存の形:

```json
{"id": "m74", "name": "ミスリルゴーレム", "element": "thunder", "rarity": 4, "role": "tank",
 "family": "コンストラクト科", "tribe": "ゴーレム族", "species": "machina", "statType": "堅牢",
 "hp": 271, "str": 33, "pdef": 22, "mdef": 33, "spd": 34, "hate": 45,
 "desc": "…", "sprite": "74"}
```

`docs/design/新規モンスター30体.json` の `st` をそのまま移せます。
`id` は既存と衝突しない番号、`sprite` は `tools/sprite_map.json` の番号。
属性は 炎/火=fire 水=water 草=grass 地/土=earth 雷=thunder 風=wind 光=light 闇=dark。
**フェニクスだけステータスが無い**ので、先に決めるか、いったん飛ばしてください。

### 2. MONSTER_KITS に30体ぶんのスキルを書く

**ここがいちばん重い作業です。** json のスキルは日本語の仕様文なので、
既存キットと同じ形の動くコードに落とす必要があります。
書式は `index.html` の `MONSTER_KITS` の直前にコメントがあります。

**先に `docs/design/新状態異常.json` を見てください。** 石化・呪い・恐慌・魅了・拘束・麻痺など、
エンジンに無い状態異常が出てきます。これを先に足さないとキットが書けません。
既存の状態異常は `statuses` オブジェクト(burn / poison / stun など)で管理されています。

### 3. 遺物のためにエンジンへ stat を足す

設計資料の遺物が使っていて `applyStatBonus` にまだ無いもの:

- **会心倍率(critDmg)** … いまは `BASE_CRIT_MULT` 1.5 固定
- **通常攻撃ダメージ(normalDmg)** … 通常攻撃だけを伸ばす
- **被ダメージカット** … 仕組み(`cut`)はあるが `RELIC_STAT_LABEL` に項目が無い

### 4. RELICS に56種を足す

`docs/design/新規遺物56種.json` が `base`(Lv1の実数) / `fx`(効果3段) / `conds`(条件) を持っています。

## 決まっていること(蒸し返さないこと)

- 遺物のスキル枠は**スキルごとに比重を変えない**。★5ガチャ産は15〜30パーセント、配布は10〜20パーセント
- **ガチャ産と配布は完全に分ける**
- 遺物の名前は**効果ではなく見た目とストーリー**から付ける
- ティアのレベル帯は昇格の上限Lvに合わせる(極上級150〜200 / 伝説級210〜250 / 神話級260〜300)
- ★8/★9/★10 の上限Lvは 230 / 260 / 300。必要ソウルは現状より安くしない
- メインクエストは神話級で打ち止め。今後はイベント側を伸ばす
- マーメイドとスケルトン弓兵の攻撃タイプは現状維持(魔法化しない)
