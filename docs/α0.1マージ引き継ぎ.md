## 立ち絵について

リポジトリ直下の `sprite_XXXX.png` はアップロードされたままの原寸画像で、
ファイル名が連番のため中身が分からない状態でした。
確認ツールのサムネイルと画像の指紋(16x16に潰した明暗パターン)で突き合わせ、
27体ぶんの対応を確定しています。

- `tools/match_sprites.py` … 突き合わせを行い `tools/sprite_map.json` を書く
- `tools/sprite_map.json` … 名前 → ファイル名 → sprite-data の番号
- `tools/add_sprites.py` … PNGを 256x256 のwebp(既存と同じ形)にして index.html に入れる

**30体すべての立ち絵がそろっています。** 後から届いた シームルグ・サキュバス・死神 は
`dreamina-*.png` として置かれていたもので、目視で確認して 163〜165 を振りました。
`match_sprites.py` は既に振った番号を変えないので、回し直しても sprite-data はずれません。

リポジトリ直下には、どのキャラにも割り当てていない画像が残っています(α0.1の30体には含まれない):

- `sprite_2784.png` … メデューサに似た別の絵(下半身が蛇)。いまのメデューサは `sprite_1949.png`
- `dreamina-2026-09-25-5245` / `-5290` / `-5833` / `-9810` … 鉢巻の雉・桃太郎風の少年・鉢巻の柴犬・スライム

## 残りの進め方(おすすめの順)

### 1. MONSTERS に30体を足す
`index.html` の `monster-data` (JSON) に追記します。既存の形:

```json
{"id": "m74", "name": "ミスリルゴーレム", "element": "thunder", "rarity": 4, "role": "tank",
 "family": "コンストラクト科", "tribe": "ゴーレム族", "species": "machina", "statType": "堅牢",
 "hp": 271, "str": 33, "pdef": 22, "mdef": 33, "spd": 34, "hate": 45,
 "desc": "…", "sprite": "74"}
```

確認ツールの `MONS` が `st:{hp,str,pdef,mdef,spd,hate}` を持っているので、そのまま移せます。
`id` は既存と衝突しない番号(m136〜 など)、`sprite` は `tools/sprite_map.json` の番号。
属性の対応は 炎=fire / 水=water / 草=grass / 地=earth / 雷=thunder / 風=wind / 光=light / 闇=dark。

### 2. MONSTER_KITS に30体ぶんのスキルを書く
**ここがいちばん重い作業です。** 設計資料のスキルは日本語の仕様文なので、
既存キットと同じ形の動くコードに落とす必要があります。既存の書き方は
`index.html` の `MONSTER_KITS` を参照(7476行あたりにキットの書式コメントあり)。

新しい状態異常(石化・呪い・恐慌・魅了・拘束・麻痺)が仕様に出てきます。
**エンジンに無いものは先に足す必要があります。** 既存の状態異常は
`statuses` オブジェクト(burn / poison / stun など)で管理されています。

### 3. 遺物のためにエンジンへ stat を足す
設計資料の遺物が使っていて、`applyStatBonus` にまだ無いもの:

- **会心倍率(critDmg)** … 会心時の倍率を上げる。いまは `BASE_CRIT_MULT` 1.5 固定
- **通常攻撃ダメージ(normalDmg)** … 通常攻撃だけを伸ばす
- **被ダメージカット** … 仕組み(`cut`)はあるが `RELIC_STAT_LABEL` に項目が無い

### 4. RELICS に56種を足す
確認ツールの `RELICS` が `base` / `fx`(効果3段) / `conds`(条件) を持っています。
遺物の数値ルールはセッションで決めた通り:
**ガチャ産は STR15〜30%、配布は 10〜20%。スキル1/2/3で比重を変えない。**
