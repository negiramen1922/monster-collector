## 実装で決めたこと(設計資料に書いていなかった部分)

資料に仕様が無かったものや、そのままでは動かないものは次のように決めました。数値を変えたいときは
`index.html` の該当キット(`MONSTER_KITS.m1xx`)を直してください。

- **フェニクスのステータス**(資料では未確定): HP200 / STR52 / 物防10 / 魔防14 / SPD42 / HATE22。
  キットは「自分を燃やして火力を上げ(やけど中は与ダメージ+20%)、やけどで倒れても灰になって
  次の自分のターンにHP50%でよみがえる(1戦闘5回まで)」
- **麻痺**: 気絶と同じく次の行動を休む(1ターン)。演出だけ別
- **魅了**: かかった側のターンで、半分は見とれて休み、半分は味方を通常攻撃する
- **混乱**: 攻撃の対象が50%で味方側になる。バフ・回復・敵へのデバフ付与は向きが変わらない
- **恐慌**: 命中率-30% のデバフとして実装(状態異常ではなくバフ欄)。**呪い**は「受けるダメージ+10%」のデバフ
- **命中率**: エンジンに無かったので追加。攻撃側の命中率ダウンが、相手の回避率に足される(最大95%)
- **必ず先制**(ペルセウス・ゼピュロスのスキル1): そのスキルが撃てるラウンドは、SPDに関係なく先頭で動く
- **アイオロスのパッシブ**: 「最速で行動した時」= ラウンドで一番先に動いたとき。累積に上限が無いと
  長期戦で止まらないので、最大+25%(5段)にした
- **雷獣のパッシブ**「SPDが一定以上の相手」: SPD40以上
- **土蜘蛛の命の糸**: 自分以外でHPの割合が一番低い味方を守る(その味方への攻撃を丸ごと肩代わり)
- **セルキー・メリュジーヌの「味方単体」**: HPが30%以下の味方、いなければ狙われやすい(HATEが高い)味方
- **ガーゴイル・アイアンスライム・マグマスライム**の「この間」: スキルを使ってから自分の2ターンの間
- 1回の行動の中で、味方を選ぶ効果(回復→バフなど)は同じ相手に当たるようにした

## 立ち絵

リポジトリ直下の `sprite_XXXX.png` はアップロードされたままの原寸画像で、
ファイル名が連番のため中身が分かりませんでした。確認ツールのサムネイルと
画像の指紋(16x16に潰した明暗パターン)で突き合わせて対応を確定しています。

- `tools/match_sprites.py` … 突き合わせて `tools/sprite_map.json` を書く
- `tools/sprite_map.json` … 名前 から ファイル名 から sprite-data の番号
- `tools/add_sprites.py` … PNGを 256x256 のwebp(既存と同じ形)にして index.html に入れる

**30体すべての立ち絵がそろっています。** 後から届いた シームルグ・サキュバス・死神 は
`dreamina-*.png` として置かれていたもので、目視で確認して 163〜165 を振りました。
メデューサは後から届いた `sprite_2784.png`(下半身が蛇の絵)に差し替えました(ユーザー指定)。
以前の `sprite_1949.png`(紫の服の絵)は使っていません。
`match_sprites.py` は `sprite_map.json` に書いてある対応と番号を優先するので、回し直しても変わりません。

リポジトリ直下には、どのキャラにも割り当てていない画像が残っています(α0.1の30体には含まれない):

- `dreamina-2026-09-25-5245` / `-5290` / `-5833` … 鉢巻の雉・桃太郎風の少年・鉢巻の柴犬
- `dreamina-2026-09-25-9810`(魚と核が見えるスライム)は、既存のシースライムの立ち絵として使った(α0.1.018)

絵が増えたら `match_sprites.py` を回し直してから `gen_design_docs.py` を実行してください(設計資料のmdに立ち絵の有無が出ます)。

```
python3 tools/extract.py          # index.html から tools/game.js と mons.json を作る
cd tools && node <テスト名>.js     # 各種テスト
CHROMIUM_PATH=/opt/pw-browsers/chromium python3 tools/notices_ui_test.py   # 画面を実際に開く
```

## 決まっていること(蒸し返さないこと)

- 遺物のスキル枠は**スキルごとに比重を変えない**。★5ガチャ産は15〜30パーセント、配布は10〜20パーセント
- **ガチャ産と配布は完全に分ける**
- 遺物の名前は**効果ではなく見た目とストーリー**から付ける
- ティアのレベル帯は昇格の上限Lvに合わせる(極上級150〜200 / 伝説級210〜250 / 神話級260〜300)
- ★8/★9/★10 の上限Lvは 230 / 260 / 300。必要ソウルは現状より安くしない
- メインクエストは神話級で打ち止め。今後はイベント側を伸ばす
- マーメイドとスケルトン弓兵の攻撃タイプは現状維持(魔法化しない)
