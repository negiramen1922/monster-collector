# モンスター資料

いま遊べるモンスターの数・立ち絵・性能をまとめたもの。数字は 2026/10/20 時点（α0.5.005）。

## 作り方

```
python3 tools/mon_sheet.py [出力先.html]   # 省略時は /tmp/monster_sheet.html
```

`index.html` から立ち絵と能力を読んで、1枚もののHTMLを書き出す。属性・種族・ロール・レア度で
絞り込める格子と、数値を並べた表、1体ずつの詳細（基礎値・通常/スキル1/スキル2/奥義・パッシブ・
星刻特性）が入っている。

**出力したHTMLはリポジトリに入れない。** 立ち絵のぶんで3.7MBあり、中身は index.html と同じなので、
二重に持つ意味がない。見たいときに作り直す。モンスターを足したり数値を直したときも同じ。
この資料の数字も、そのとき一緒に書き直す。

**154体**

|---|---|
| レア度 | ★5 14 / ★4 39 / ★3 47 / ★2 30 / ★1 24 |
| 属性 | 闇 23 / 火 21 / 土 21 / 水 18 / 光 18 / 草 16 / 風 16 / 雷 13 / 無 8 |
| 種族 | ビースト 41 / セレスティア 26 / ヒューム 17 / デーモン 16 / アンデッド 12 / エルフ 10 / マキナ 9 / ドワーフ 9 / アモルファス 8 / ドラコニア 6 |
| ロール | アタッカー 52 / タンク 37 / サポート 31 / シューター 24 / トリックスター 10 |

科は17種（ワイルド科23・ミスティック科19・デミヒューマン科13・アンデッド科12・アヤカシ科12 ほか）。
全員ぶんのキット（通常・スキル1・スキル2・奥義・パッシブ）が `MONSTER_KITS` に入っていて、
ロール既定のキットで済ませている子はいない。

星刻特性（★6〜★10）が入っているのは30体。

## 気づいたこと（未対応）

- **m128〜m135 の8体に科が入っていない。** フレイムリザード・ヒノコ・ストームホーク・
  ポンドフロッグ・ボルトビートル・ピクシー・マッドモール・カマイタチ。科は攻撃モーション
  （`FAMILY_MOTION`）の引き当てにも使うので、入れておきたい。資料では赤で「(科なし)」と出る。
- **`statType` が「現行値」のままの22体がいる。** マンイーター〜シースライムあたりの古い組で、
  ほかは「俊敏」「剛力」のような傾向の名前が入っている。表示には使っていないので害はないが、
  傾向で絞り込みたくなったときに揃っていない。

## バランスの偏り（数えただけ・良し悪しの判断はしていない）

- ビーストが41体で、次のセレスティア26体の1.6倍。10種族のうち上位2つで全体の43%。
- トリックスターだけ10体で、ほかのロールの3分の1以下。
- 無属性は8体で据え置き。無属性はどの属性とも1.0倍なので、相性で縛るステージ（バベルなど）では
  罰も得もない枠として効いてくる。

`tools/mon_sheet.py` に足す。
