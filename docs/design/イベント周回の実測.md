# イベント中に主役★5を完凸するまで（実測・2026-09-30）

「ガチャで主役を1体引いたあと、EX3周回とイベントステージの石割でどれくらいで完凸できるか」の集計。
測ったスクリプトはスクラッチパッド（`ev/soul.js`）。**この文書は測定結果だけで、仕様変更はしていない。**

## 測った編成

本人の本気編成（BP 100,666）に寄せたもの。

- アバドン(m139) / フェンリル(m68) / タイタン(m54) / 九尾の狐(m116)
- ★10・**Lv220**・ワザLv10・ルーンⅩ金×4・遺物★5 Lv80（餅遺物があるものは餅遺物）

## 1戦あたり（各120戦）

| | 勝率 | 手番 | ラウンド | ×4速の実時間 |
|---|---|---|---|---|
| EX1 | 100% | 7.7 | 3.1 | 約8秒 |
| EX2 | 100% | 20.1 | 4.5 | 約11秒 |
| **EX3** | **100%** | 21.4 | 4.6 | **約11秒** |
| イベントステージ10 | 100% | 19.4 | 5.7 | 約11秒 |

実時間 = 手番数 × `ACTION_DELAY_MS`(950ms) ÷ 速度 ＋ 結果画面など6秒（この6秒は見積もり）。
**この編成では EX3 も100%勝てる**ので、EX3 は腕試しではなく純粋な周回先になっている。

## 完凸まで（★5→★10 = 4,800ソウル）

| | EX3の1戦 | EX3だけで完凸 |
|---|---|---|
| いまのイベント（100%×1個） | 1.000 | **4,800戦 = 14.8時間** |
| soulV2 のイベント（50%×平均1.65個） | 0.825 | **5,819戦 = 17.9時間** |

イベントショップの主役ソウル300個を引くと **4,500戦 ≈ 13.8時間 / 5,450戦 ≈ 16.7時間**。
PUイベントは2週間開催なので **1日1時間ほど**。

**EXステージは周回（オート）が使えない**（`sweepAllowed` が `stage.ex` を弾く）ので、この時間はすべて手動。

## 石割はソウルには効かない

イベントステージ10は **20スタミナで0.2ソウル**（`eventBossSoulRate` = ステージ番号×2%）。
つまり **100スタミナで1ソウル**。

- 14日ぶんの自然回復 4,032 ＋ スタミナ回復ショップ全部 3,300（**5,100石**）= 7,332スタミナ
- → **73ソウル**（4,800の **1.5%**）。石割ぶんだけなら33ソウル

**ソウル目的の石割は成立していない。** イベントステージはメダルの回収場所と割り切るのが正しい。

## 決めたこと

- **EXを周回可能にはしない。** EXはスタミナを使わないので、周回を許すと上限がなくなる
- **EX3のソウル率も上げない。** 完凸は強い。ガチャの重複でもソウルは入る（主役の重複は 150＋ピックアップ150 = 300／体）
- **イベントショップの主役ソウルも増やさない。** 300個 = ★5→★6 ちょうど1段ぶんで足りている
- ゆるめるならソウルではなく**メインクエストの素材ドロップ**のほう（案は `ワザ強化素材の物価.md` と引き継ぎに）
- PUイベントは**2週間開催**をルールにする
