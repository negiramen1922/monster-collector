# ワザ強化素材の物価（α0.3.004）

メインクエストでワザ強化素材が余りすぎていた（神話級ハードのボス1周で **TierI 換算 827 個**、
1体を完凸するのに **8 周**）のを直した記録。狙いは

> **極上級までは素材で詰まらない。神話級に挑むときだけ TierIV がブレーキになる**

という形にすること。実装は `index.html`、数字の検証は `tools/mat_economy_test.js`。

---

## 1. 仕組み：期待値 + 抽選

`QUEST_TIERS[].drops` は `[TierI, TierII, TierIII, TierIV]` の **期待値**（小数可）。
実際に落ちる個数は毎回抽選する（`rollDropCount`）。

```
枠数 n = max(1, round(期待値 × 2))
1枠あたり p = 期待値 ÷ n
n 回ふって当たった数だけ落ちる
```

- 平均はぴったり期待値どおり。出る数は毎回ブレる（期待値7 → だいたい 5〜9、まれに 0 や 14）
- **期待値が1を割ると、そのまま「N%で1個」の確率ドロップになる** → TierI〜TierIV を1本のルールで書ける
- 表示は「出る可能性のあるもの」をアイコン＋名前＋個数で並べる（`dropIconsHtml`）。確率は出さない。
  個数は **1種ぶんの幅**（`dropKindRange`）— 落ちた素材は3種にランダムで割り振られるので、1種あたりの確率は 1/3。
  出る可能性があるものは上を最低1個にして `0-1` と出す

### ボスとハードは倍率

足し算ではなく**すべてのTierの期待値に倍率**をかける（`scaleDropTiers` / `dropMul`）。

| | 倍率 |
|---|---|
| ボス | `DROP_MUL_BOSS` = **1.6** |
| ハード | `DROP_MUL_HARD` = **1.5** |
| ハードのボス | 両方が乗って **2.4** |

落ちないTier（期待値0）は倍率をかけても0のまま。

### TierIV の1日5個

`MAT_T4_DAILY_CAP = 5`。抽選で出た数を `matT4Left()` で頭打ちにし、取れた数を
`STATE.daily.counts.mat4` に積む。**上限に当たっても TierI〜TierIII は変わらず落ちる**ので
周回そのものは止まらない。1日28周ぶんの期待は 神話級ハードボス 5.04個 / 伝説級ハードボス 4.03個 なので、
**いちばん上だけが上限にちょうど当たる**。

周回（`renderSweepModal`）で上限を超える回数を選ぶと、先に警告を出す。

`matT4Today()` は画面の描画からも呼ぶので `ensureDaily()` を使わない（日付が変わったときに
ログイン回数まで数えてしまう）。読むだけにして、書くのは抽選のときだけ。

## 3. 何周かかるか

1体のワザを**ぜんぶ Lv12**（スキル1・スキル2・奥義・パッシブ）にするのに必要なのは

| | TierI | TierII | TierIII | TierIV | TierI 換算 |
|---|---|---|---|---|---|
| 1体ぶん | 712 | 232 | 48 | 24 | **6,072** |

`SKILL_MAT_COST` の合計 × 2種 × 4系統。メインは1周10スタミナ、自然回復は1日288 → **1日28周**。

| 周回先 | 1周 TierI 換算 | 完凸まで |
|---|---|---|
| 極上級ハードボス | 48.3（ドロップ34.8＋TierIV枠13.5） | 126周 / 4.5日 |
| 伝説級ハードボス | 58.2（ドロップ40.2＋TierIV枠18.0） | 105周 / 3.7日 |
| 神話級ハードボス | **66.7**（ドロップ44.4＋TierIV枠22.3） | **92周 / 3.3日** |

内わけ（神話級ハードボス）：TierI 17 ＋ TierII 20 ＋ **TierIII 7** ＋ TierIV枠 22 = 66.7。

**ワザ Lv10 まで**（★5でも届く範囲）は TierIV を1個も使わない。
極上級ハードのボスで **89周 / 3.2日**。ここが「詰まらない」ほうの数字。

### なぜこの配分か

- 前は 8 周。合意した「100周相当」に寄せた（TierIV の上限を 2→5 にしたぶん 114周 → 92周）。
- TierIV が要るのは **ワザ Lv10→11 と Lv11→12 だけ**。ワザLvの上限は ★6=10 / ★7=11 / ★8以上=12 なので、
  TierIV は放っておいても終盤しか効かない。1日5個の上限は序盤・中盤に何も影響しない。
- 難度が上がるほど **上のTierの比率**が上がる（TierI は 4→7 でゆるやかに増えるだけ）。
  神話級を回る理由は TierI の数ではなく TierIII・TierIV。

## 4. 錬金術（合成）

拠点の「錬金術」。**同じ種類の1つ下のTier×5 → 1個**（`craftMat` は `matKey(fam, kind, toTier - 1)` しか見ない）。
**種類はまたげない** — アタッカーの証からシューターの証は作れないし、属性の欠片から種族の魂も作れない。

`matTierUnlocked()` = クリアしたステージで落ちるいちばん上のTier。そこまでは 5個→1個、
それより先回りすると `CRAFT_RATIO_AHEAD = 15` 個→1個。
（初級=I / 中級=II / 上級から III・IV。`MAT_TIER_FROM` と `MAT_TIER_ROUTE` はドロップ表から自動で作る）

## 5. ワザ素材BOX

**メインステージ・ハード・イベントステージからは出ない。** 回収場所は
**ショップ（ゴールド）・イベントショップ・深淵回廊・PVPショップ**。

かわりに初回クリアでそのステージの素材そのものを配る。

| | 配るもの | TierI 換算 |
|---|---|---|
| 初級ボス | TierI × 25 | 25 |
| 中級〜神話級のボス（ステージ1〜9） | TierII × 15 | 75 |
| ステージ10のボス | TierIII × 5 | 125 |
| ハードのボス | 同じ素材の **2倍** | ×2 |
| イベントステージ 1〜5 | 主役の3種 × TierII 各6個 | 90 |
| イベントステージ 6〜10 | 主役の3種 × TierIII 各2個 | 150 |
| チュートリアル3つめ | 初級1ステージの3種 × TierI 各7個 | 21 |

種類は**ステージ番号で決める**（毎回抽選すると、出撃前に見た報酬と違うものが出てしまう）。
`buildBossMatRewards()` は `rebalanceDropKinds()` と `buildHardStages()` のあとに呼ぶ
（kinds が入れ替わるので、先に決めると表示とズレる）。

**のこっている穴**：`box_sel_4` はいま **深淵回廊25階ごと**とミッションでしか手に入らない。
ゴールドショップは TierIII まで。PVPショップは PVP 自体が未完成なので、いまは足さない。
深淵回廊の報酬を厚くする予定があるので、そこで吸収する。
