# ワザ強化素材の物価（α0.3.004）

メインクエストでワザ強化素材が余りすぎていた（神話級ハードのボス1周で **TierI 換算 827 個**、
1体を完凸するのに **8 周**）のを直した記録。狙いは

> **極上級までは素材で詰まらない。神話級に挑むときだけ TierIV がブレーキになる**

という形にすること。実装は `index.html`、数字の検証は `tools/mat_economy_test.js`。

---

## 1. 決めたこと

| | 中身 |
|---|---|
| ドロップ | ステージが落とすのは **TierI と TierII だけ**。TierIII は1個も落ちない |
| TierIII | **拠点の「錬金術」で合成するだけ**（TierII×5 → TierIII×1） |
| TierIV | **上級以上のボスだけが確率で落とす**。上級 3% / 超上級 5% / 極上級 7% / 伝説級 10% / 神話級 12%（ハードも同率） |
| TierIV の上限 | **1日2個**。上限に当たっても TierI・TierII は変わらず落ちる（周回そのものは止めない） |
| 合成倍率 | **5個 → 1個**（据え置き）。TierIV = TierIII×5 = TierII×25 = TierI×125 |
| 先回り | 解放前のTierも作れるが **15個 → 1個**。正規の効率（5個→1個）に変わるのはクエストの進みぐあいで：中級=TierII / 上級=TierIII / 超上級=TierIV |

### ドロップ量

素のドロップ（雑魚ステージ）。`QUEST_TIERS[].drops` は `[TierI, TierII]`。

| 難易度 | TierI | TierII | ボスの TierIV |
|---|---|---|---|
| 初級 | 4 | – | – |
| 中級 | 5 | 1 | – |
| 上級 | 6 | 1 | 3% |
| 超上級 | 8 | 2 | 5% |
| 極上級 | 10 | 2 | 7% |
| 伝説級 | 12 | 3 | 10% |
| 神話級 | 15 | 3 | 12% |

ボスとハードは**量だけ**増える（出るTierの上限は変わらない）。落ちないTierは0のまま。

| | TierI | TierII |
|---|---|---|
| ボス | +2 | +1 |
| ハード | +4 | +1 |
| ハードのボス | +6 | +2 |

→ 神話級ハードのボス = **TierI×21・TierII×5**（TierI 換算 46）＋ TierIV 12%

## 2. 何周かかるか

1体のワザを**ぜんぶ Lv12**（スキル1・スキル2・奥義・パッシブ）にするのに必要なのは

| | TierI | TierII | TierIII | TierIV | TierI 換算 |
|---|---|---|---|---|---|
| 1体ぶん | 712 | 232 | 48 | 24 | **6,072** |

1系統につき素材2種類を食うので `SKILL_MAT_COST` の合計 × 2 × 4系統。
メインは1周10スタミナ、スタミナの自然回復は1日288 → **1日28周**。
TierIV は1日2個で止まるので、1周ぶんに割り戻すと `2×125 ÷ 28 = 8.9`。

| 周回先 | 1周 TierI 換算 | 完凸まで |
|---|---|---|
| 極上級ハードボス | 44.9（ドロップ36＋TierIV枠8.9） | 136周 / 4.8日 |
| 伝説級ハードボス | 51.9（ドロップ43＋TierIV枠8.9） | 117周 / 4.2日 |
| 神話級ハードボス | **54.9**（ドロップ46＋TierIV枠8.9） | **111周 / 3.9日** |

**ワザ Lv10 まで**（★5でも届く範囲）は TierIV を1個も使わない。
極上級ハードのボスで **86周 / 3.1日**。ここが「詰まらない」ほうの数字。

### なぜこの配分か

- 前は 8 周。「合意した100周相当」に寄せた（111周）。
- 合成倍率を 5 のままにすると TierIV が TierI 換算 125 と重いので、そのぶん **TierI・TierII のドロップ量を増やした**（TierI 12→21・TierII 8→5 だが、TierIII・TierIV の確定ドロップが消えたぶんで差し引き -94%）。
- TierIV が要るのは **ワザ Lv10→11 と Lv11→12 だけ**。しかもワザLvの上限は ★6=10 / ★7=11 / ★8以上=12 なので、TierIV は放っておいても終盤しか効かない。1日2個の上限をかけても序盤・中盤は何も変わらない。
- 1日2個は「上限に当たったら周回をやめる」形ではなく、**当たっても TierI・TierII は落ち続ける**。合成の材料を稼ぐ周回は止まらない。
