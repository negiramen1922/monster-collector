# 九尾「狐火の祭壇」・タイタン「巨神の遺跡」のEX（α0.3.006）

`ev_kyubi` / `ev_titan` にはEXが無かった（`EVENT_EX` に載っていなかった）ので新しく作った。
ステージ効果は本人の案をそのまま、engine で書ける形に置き換えたもの。

---

## 1. 狐火の祭壇（九尾）

> 狐火に炙られた敵ほど深く斬れる。そのかわり刃は通りにくく、敵は速い。

| 効果 | 書きかた |
|---|---|
| 味方 やけど状態の敵へ 与ダメージ+50% | `{ side:'ally', dmgDealt:0.5, whenTarget:'burned' }` |
| デーモンの味方 最大HP+50% | `{ who:{species:'demon'}, side:'ally', stat:{hp:0.5} }` |
| シューターの味方 STR+50% | `{ who:{role:'shooter'}, side:'ally', stat:{str:0.5} }` |
| 敵 物理防御+40%（物理が通りにくい） | `{ side:'enemy', stat:{pdef:40} }` |
| 敵 SPD+50% | `{ side:'enemy', stat:{spd:0.5} }` |
| **EX3のみ** 敵 最大HP+150%・STR+40% | `{ side:'enemy', stat:{hp:1.5,str:0.4} }` |

「物理耐性+200%」は **防御の割合化で素直に書けるようになった**。
以前は `stat:{pdef:2}`（物防×3）と書いても実測 4.2R → 4.1R でほぼ無意味だったが、
いまは防御がそのままカット%なので `pdef: 40` で **+40%カット**。
敵の素の物防が 6〜16 なので、EXでは **46〜56%カット**になる。

敵は炎属性を半分以上にして、味方が「やけどを入れて殴る」動きを取りやすくしてある。

## 2. 巨神の遺跡（タイタン）

> 石の巨人は毒も炎も気絶も受けつけない。殻を割るのは、殻をまとった者だけ。

| 効果 | 書きかた |
|---|---|
| 味方 シールドを持っているあいだ 与ダメージ+50% | `{ side:'ally', dmgDealt:0.5, when:'shielded' }` |
| ドワーフの味方 最大HP・STR+50% | `{ who:{species:'dwarf'}, side:'ally', stat:{hp:0.5,str:0.5} }` |
| 敵 シールドの効果量+100% | `{ side:'enemy', shield:1.0 }` |
| 敵 気絶にかからない | `{ side:'enemy', immune:['stun'] }` |
| 敵 やけど・毒にかからない | `{ side:'enemy', immune:['burn','poison'] }` |
| **EX3のみ** 敵 最大HP+200%・STR+100% | `{ side:'enemy', stat:{hp:2.0,str:1.0} }` |

「シールドを持っているとき攻撃力+50%」は `stat.str` では書けない（`stat` は戦闘に入るとき
1回だけなので条件付きにできない）。`dmgDealt` + `when:'shielded'` で同じ効きにしてある。

**注意**：シールドを張れるモンスターは **タイタン・ブロック・アイスゴーレム・カーバンクル の4体だけ**。
味方側でこの効果を使うにはそのどれかか「旅人の盾」が要る。**タイタン本人を持っていると有利**という
作りになっているが、持っていない人には効果が1つ死ぬ。
敵側は タイタン・ブロック・アイスゴーレム を必ず入れて、「敵のシールド+100%」が空振りしないようにした。

## 4. 難度（実測・各60戦）

| | 素の編成<br>★4 Lv70・装備なし<br>BP 22,000 | 中盤<br>★5 Lv165・遺物ルーンあり<br>BP 61,000 | 本気編成<br>★10 Lv220<br>BP 100,000 |
|---|---|---|---|
| 狐火の祭壇 EX1 | **100%**（7.3R） | 100% | 100%（3.0R） |
| 狐火の祭壇 EX2 | 0% | **92%**（14.2R） | 100%（3.4R） |
| 狐火の祭壇 EX3 | 0% | 0% | **62%**（6.5R） |
| 巨神の遺跡 EX1 | **95%**（11.2R） | 100% | 100%（3.0R） |
| 巨神の遺跡 EX2 | 0% | **100%**（15.3R） | 100%（4.1R） |
| 巨神の遺跡 EX3 | 0% | 0% | **52%**（21.3R） |

狙いどおりの段差になった。

- **EX1**: EXが開いた直後（★4 Lv70・装備なし）でも勝てる
- **EX2**: 中盤の編成の壁
- **EX3**: **本気編成でも半々**。既存のEX3（アバドン・フェンリル）は本気編成で勝率100%だったので、
  ここが初めて「腕試し」になる

### EX3を本気編成に対して効かせるレバー

測った結果、**イベントごとに効くレバーが違った**。

| | 九尾 | タイタン |
|---|---|---|
| 敵HPだけ上げる | +250%でも 78% | +250%で 65%（24R・時間切れ負けが増える） |
| 敵STRだけ上げる | **+50%で 43%**（鋭く効く） | +180%でも 100%（味方が耐えきる） |
| 採用 | HP+150% **STR+40%** | **HP+200%** STR+100% |

九尾は「速くて痛い」ので STR が効き、タイタンは「硬い」ので HP を積まないと終わらない。
**タイタンEX3は21ラウンドの長期戦**になるが、テーマ（石の殻を割る）としては正しいので残した。
ただし★3条件（ウェーブ数×4 = 12ラウンド）には届かない。

## 5. 足した仕組み

`buildEventExStages` に **EX1〜3のうち特定の面だけのルール**（`t.rules`）を足せるようにした。

```js
rules: t.rules ? [...meta.rules, ...t.rules] : meta.rules,
```

これが無いと「EX3だけ敵を硬くする」が書けず、EX1まで巻き添えになる。

テストは `tools/event_ex_test.js`。
