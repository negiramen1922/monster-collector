### 測るときの落とし穴（実際にはまったもの）
- **`STATE.autoUlt` は既定 false**。プレイヤー側の必殺技は自動では出ません。測るときは `load('game.js', s => s.replace('autoUlt: false,', 'autoUlt: true,'))` が要ります。忘れると全員0回になります。
- **`buildUnit(mon, stageLevel, isEnemy, star, boss, charLevel, upgrades)`**。味方は第6引数 `charLevel` にレベルを渡さないと育ちません（第2引数は敵用のステージレベル）。
- 敵のBPは `battlePower()` が使えません（プレイヤーの所持データを見るため）。`tools/gen_eventdata.js` の `bpOf` と同じ式を使ってください。

## 4. ユーザーとの進め方（守ること）

- **main へは、ユーザーが「入れていい」と言ったときだけ push。** それ以外は `claude/confident-meitner-d5qc5m` に push。
- **一度決めたことを聞き直さない。** 決定は上の JSON に入っています。
- **新しい案を出すときは、必ず前の案と並べて出す。** 値段・数値を変えたら「前 → 後」の表を付けること。
- **PR は言われたときだけ作る。**
- **コミットメッセージに model 名を書かない。**
- 数字を出すときは実測する。採点式と実測が食い違ったら実測を信じて、採点式のほうを直す（肩代わりの値付けは実測に合わせて 12→24→31 点に直した経緯がある）。
- 間違えたらはっきり訂正する。ユーザーは訂正を歓迎するが、黙って直すのを嫌う。
