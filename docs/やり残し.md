## 1. 優先度：高（次にやるならここから）

### 1-1. タンクとサポーターの奥義が撃てない
- **症状**：タイタンは1ステージ 0.00 回、九尾 0.08〜0.16 回。アタッカーは 0.6〜1.6 回。
- **原因**：SPの入りが「行動+10 / 被弾+5（1ラウンド上限10）/ 撃破+15」で、撃破ぶんが大きい。前で殴られる役ほどSPが溜まらない。
- **案**：被弾のSP上限をロールで変える（タンク25 / サポーター15 / ほか10）＋ 足りないキャラだけ個別にコストを下げる。
- **資料**：`docs/design/タイタンの必殺技_粗調整.json` の `sp_mondai`。実測は `tools/balance/sp_probe.js` / `tank_probe.js`。
- **注意**：測るときは `STATE.autoUlt` が既定 false なので `load('game.js', s => s.replace('autoUlt: false,', 'autoUlt: true,'))` が要ります。

### 1-2. イベント終了時の未受け取り
- いまは **メダルと一緒にミッションの進みぐあいも消える**（未受け取りの報酬も受け取れなくなる）。ミッション画面に警告を出してあります。
- 設計資料（`docs/design/イベントショップとガチャ券.json` の `mission`）には「未受け取りだけは残す」と書いてあるので、**資料と実装が食い違っています**。
- 残す方に倒すなら：`clearEndedEventMedals()` の `delete STATE.evMission[ev.key]` を外し、メダル報酬を星結晶などに振り替える必要があります（メダルは消えるので、そのままでは価値0になる）。

### 1-3. 周回券の入手先
- アイテムと使う仕組み（`SWEEP_TICKETS` / `runSweep(id, times, useTicket)`）は入っていますが、**どこからも手に入りません**（星結晶ショップからは外しました）。
- ミッション報酬・ログインボーナス・イベントショップのどれで配るか決めていません。
- 設計資料の注意：**イベントに使える周回券は作らない**（メダルの見積もりが崩れるため）。

## 2-6. 貸し出し(お助けモンスター)が強すぎる

強い人の強いモンスターを借りると、本来まだ勝てないステージを一気に抜けられる。
いまの抑えは「編成に入れると出撃スタミナ +5(`HELP_STAMINA_SURCHARGE`)」だけ。
α0.2.007 で遺物とルーンも乗るようになったので、さらに効くようになった。

案は `docs/design/今後やりたいこと.json` ではなくここに書く（未決定）:

| | 中身 | 効き方 |
|---|---|---|
| A. 1日の使用回数を決める | 借りたモンスターを入れて出撃できるのは1日◯回まで | いちばん素直。日課の範囲に収まる |
| B. 推奨Lvで頭打ちにする | ステージの推奨Lvを大きく超えるぶんはLvを丸める | 「格上を借りて抜ける」だけを潰す |
| C. 借りたモンスターは報酬が減る | クリア報酬(ソウル・素材)を◯%に | 使えるが得はしない |
| D. イベント・EXでは使えない | 期間限定だけ締める | 影響が限定的 |

いまは何も入れていない。入れるなら A か B が本命。
