## 書き方

- **想定の役割(yakuwari)**: パーティの中で何を任せるか。1〜2文
- **想定の動き(ugoki)**: 新バトルシステムでの1戦の流れ(スキルは開幕から使え、スキル1→2→1と交互)
- **組ませたい相手・苦手(aite)**: 相性のよい味方、苦手な敵・編成
- **技ごとの意図(ito)**: normal / skill1 / skill2 / passive / ult ごとに、なぜこの効果にしたか
- **星刻特性の方針(seikoku)**: ★6〜★10で何を伸ばすか。確定した表の置き場所
- **実装・調整の注意(chui)**: 作るとき・数字を触るときに気をつけること
- **実測(sokutei)**: 測った条件と結果。測り直したら書き換える
